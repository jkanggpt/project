# 설계 결정 기록 (DECISIONS)

명세(`docs/SPEC.md`)가 정하지 않은 것을 정했거나, 명세를 해석한 내용입니다. 새 결정은 아래에 이어 적습니다.
형식: **결정** — 이유. (마일스톤, 날짜)

## 마일스톤 1 (2026-11-05)

### 진행 방식
- **작업 브랜치는 세션이 지정한 `claude/wizardly-allen-7ou35f`** — 클라우드 세션이 이 브랜치에만 푸시하도록 지정되어 있어서, SPEC 의 `m1-foundations` 대신 이 이름을 썼습니다. 다음 마일스톤도 세션이 지정한 이름을 따르고, PR 제목에 마일스톤을 적습니다.

### 시간
- **1배속에서 한 틱(게임 속 10분) = 0.5초, 하루 = 72초** — 왕성 목표가 50일쯤(SPEC §8)이므로 1배속 60분, 3배속 20분 정도로 한 판이 끝납니다. 값은 C(`clock.h` `CLOCK_REAL_MS_PER_TICK`)에 있고 Godot 은 `core_get_config` 로 읽습니다.
- **밤 21:00~05:00, 새 게임은 1일 06:00 에 시작** — 주민이 잠잘 시간(M2)과 마물이 나오는 밤(M4)의 기준. 낮밤 색도 같은 값을 씁니다.
- **매일 자정의 "N일째 시작" 알림은 보여 주지 않음** — 너무 잦아서 새벽 알림("N일째 아침이 밝아 옵니다")으로 대신합니다. 이벤트 자체는 C 가 계속 냅니다.

### 지도
- **96×96, 성채 중심 (48, 48), 성채 3×3, 둘레 반지름 3칸은 풀밭으로 비움, 반지름 9칸 안에는 호수 없음**.
- **지형 비율: 숲 26%, 바위 9%, 물 8%, 마정석 광맥 덩어리 5~7개** — "노이즈 상위 N%" 로 칠해서 시드마다 비율이 거의 같습니다.
- **바위 지대는 지나갈 수 있지만 느림** (이동 비용: 풀밭 10, 숲 15, 바위 30, 광맥 10, 물 0=막힘). 바위가 길을 막으면 갇힌 지역이 많이 생기기 때문입니다. 채석장은 "바위 옆"(SPEC)에 지으므로 바위 칸 자체를 걸을 수 있어도 됩니다.
- **노이즈는 정수 고정소수점으로만** — 실수 계산의 플랫폼 차이로 같은 시드가 Windows/Linux 에서 다른 지도를 만드는 일을 막습니다.
- **연결성 보장: 성채에서 네 변 모두 걸어서 닿아야 하고, 갇힌 땅은 물로 바꿈** — 적은 가장자리에서 오고(M4), 떠나는 주민은 가장자리로 걸어갑니다(M2).
- **공정한 시작: 성채 반지름 14칸 안에 숲 ≥ 30, 바위 ≥ 10, 광맥 ≥ 3** — 모자라면 성채에서 7~12칸 떨어진 곳에 덩어리를 찍습니다. 3000개 시드로 확인했습니다.

### 자원
- **금화·마정석은 화폐라 저장 한도 없음, 식량·목재·석재·약초는 한도 있음 (성채 200)** — 어느 자원에 한도가 있는지는 규칙이므로 C 가 뷰의 `resource_capacity[]` 로 알려 줍니다 (0 = 한도 없음).
- **난이도별 시작 자원** (금화, 마정석, 식량, 목재, 석재, 약초): 평화 300/10/80/80/40/10, 보통 200/5/60/60/30/5, 혹독 150/3/40/40/20/3. 시뮬레이터로 M2~M7 에서 다시 맞춥니다.

### C 코어
- **라이브러리 세 벌**: `castle_core`(공유, Godot 용), `castle_core_static`(CLI 용, 실행 파일 하나로 시연하기 쉬움), `castle_core_testing`(테스트 용, 내부 헤더 공개 + 할당 실패 주입).
- **새니타이저는 정적 라이브러리·CLI·테스트에만** — ASan 이 들어간 공유 라이브러리는 Godot 이 로드할 수 없고, Ubuntu 의 clang 은 공유 라이브러리 ASan 링크에 런타임 패키지가 더 필요합니다.
- **모든 할당은 `mem_*` 감싸개로** — 테스트 빌드에서만 "k 번째 할당부터 실패"를 주입합니다. 이 카운터는 테스트 빌드에만 있는 유일한 전역 상태입니다.
- **MSVC 는 C 런타임 정적 링크(`/MT`), MinGW 는 `-static-libgcc`** — `castle_core.dll` 하나만 복사하면 되게.
- **소스는 UTF-8, MSVC 에 `/utf-8`** — 한국어 Windows(코드 페이지 949)에서 한글 주석·문자열이 깨지지 않게.
- **시드는 0 이상의 int32** — 뷰 구조체를 모두 `int32_t` 로 맞추기 위해.
- **망가진 월드는 저장을 거부** — 불변 조건을 어긴 상태를 저장하면 멀쩡한 예전 세이브를 덮어쓰게 되므로.
- **저장은 `.tmp` 에 쓰고 → 예전 파일을 `.bak` 으로 복사 → 바꿔치기** — 복사 방식이라 바꿔치기 직전까지 본 파일이 늘 있습니다.
- **비용 격자와 이벤트는 저장하지 않음** — 비용 격자는 지형에서 다시 계산되고, 이벤트는 보여 주기용입니다.
- **이벤트 큐 최대 4096개, 넘치면 가장 오래된 것을 버리고 경고 이벤트로 알림**.
- **CLI 는 Windows 콘솔에서 `ReadConsoleW` 로 읽어 UTF-8 로 변환** — 일부 Windows 에서 `CP_UTF8` + `fgets` 로 한글이 사라지는 문제를 피합니다.

### Godot
- **UI 배율은 정수(1~4), 테마 값을 곱해서 적용** — Galmuri11 은 12px 의 정수배에서만 또렷합니다. CanvasLayer 를 키우는 방식은 툴팁 팝업이 같이 커지지 않아서 테마 방식을 골랐습니다. 기본값은 창 크기로 정합니다 (1280×720 → 2, 1920×1080 → 3). 설정 메뉴(M6)에서 바꿀 수 있게 할 예정입니다.
- **창 늘이기(stretch) 끔, 카메라 확대는 정수 배율(1~6)** — 픽셀 아트가 고르지 않게 늘어나지 않도록.
- **입력 동작은 코드(`InputActions.cs`)로 등록하고 물리 키 코드를 씀** — 한글 자판/IME 가 켜져 있어도 WASD 가 동작하게.
- **지형 그림: `tools/make_art.py` 가 Kenney Tiny Town 타일과 절차적 타일(물, 바위, 광맥)로 `terrain.png` 를 만들고 커밋** — Tiny Town 에는 물·바위 지대·광맥 타일이 없습니다. 더 나은 그림이 생기면 PNG 만 바꾸면 됩니다.
- **성채는 Tiny Town 성벽·문 타일로 만든 3×3 임시 그림** — M2 에서 건물 장면으로 바뀝니다.
- **Kenney `Tiles/`, `Tiled/` 폴더는 `.gdignore` 로 Godot 가져오기에서 뺌** — 같은 그림이 `Tilemap/` 시트에 있습니다. 나머지 에셋의 `.import` 파일은 커밋합니다(uid 가 컴퓨터마다 달라지지 않게).
- **오류 감지 로거(`ErrorCounter`)는 스모크·스크린숏 모드에서만** 붙입니다. 스크립트는 출력의 `ERROR`/`WARNING` 줄도 따로 검사합니다.
- **C# 은 `ExportDebug`/`ExportRelease` 빌드에서 경고를 오류로** — Godot 의 빌드 구성은 Debug/ExportDebug/ExportRelease 입니다.
