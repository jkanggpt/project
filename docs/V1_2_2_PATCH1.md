# v1.2.2 후속 보완 — 2026-11-23

사용자의 후속 요청을 적용한 C11/raylib 실행판입니다. 원래 v1.2.2 명세의72시간 규칙보다 아래48시간 규칙이 우선합니다. 이전 릴리스의 [검증 기록](V1_2_2_QA.md)은 당시 결과이며 이번 변경의 결과와 구분합니다.

## 습격 진행

- 적의 지도 진입은 `APPROACH`입니다. 이때는 공격 타이머를 소비하거나 건설·공사·승급·수리를 잠그지 않습니다.
- 현재 시야에서 적을 처음 발견하거나 적이 첫 공격 동작을 시작하면 `ASSAULT`로 바꾸고, 그 시각부터48게임시간을 한 번만 설정합니다. 재발견·추가 공격으로 만료 시각을 연장하지 않습니다.
- 유효한 공격 대상을 계속 공략합니다. 가장 가까운 접근 면이 막혔으면 다른 면을 찾고, 도달할 수 없다면 접근 가능한 다른 시설을 선택합니다. 완료된 옛 경로도 다시 탐색하며 공사 중 건물은 공격하지 않습니다. 공통 적 생성 경로의 배열 재사용 시 HP·공격·철수 런타임을 초기화해 이전 습격 상태를 물려주지 않습니다.
- 48시간이 되면 진행 중 공격 동작과 공격 목표를 취소하고 `RETREAT`로 전환합니다. 남아 있던 재탐색 대기시간을 지워 즉시 역경로·우회 경로로 이동합니다. 이미 발사된 투사체는 기존 비행을 마칩니다.
- 철수 중 현재 시야에서 벗어난 적은 탈출로 처리합니다. 마지막 생존 적이 시야 밖으로 사라지거나 쓰러지는 즉시 종료하고 건설 잠금을 해제합니다. 지도 가장자리까지 기다리지 않습니다. 영주관 함락에 따른 패배 규칙은 유지합니다.

저장 형식v10/ABI12와 기존 슬롯은 유지합니다. 접근/전투/철수·시작/만료 시각·경유점·첫 발견 상태는 기존 필드로 저장합니다. 이전 v10의 미발견 습격은 접근 단계로 바꾸고, 이미 발견된72시간 습격은 당시 저장된 시작 시각 기준으로48시간 상한을 적용합니다. 이전 파일에는 최초 발견의 별도 시각이 없으므로 이를 임의로 복원하지 않습니다.

## 그림과 화면

농장류의 투명 여백을 제외한 실제 그림 경계를 읽어 점유 너비·높이에 맞춥니다. 경작지·농장·관개농장·과수원·텃밭의 계절/회전 선택과 건설 미리보기에 같은 경계를 사용합니다. 실제 점유/판정은 바꾸지 않습니다.

새 원화는 [프롬프트 전문](../art/V122_PATCH1_PROMPTS.json)의 내장 image_gen 호출로 제작했습니다. `art/v122_patch1/combat_fx.png`는8종×6프레임, `factions.png`는6세력 문장입니다. C 패커 `castle_ui_art`가 불균등한 행/열 간격을 감지해 이펙트가 섞이지 않도록 자르고128셀에 패킹합니다.

참격·화살·타격·발톱·불꽃·냉기·마법·폭발 이미지는 실제 피해 위치에서 재생합니다. 공격 출발점과 피해 지점으로 회전 각도를 계산하고 월드 오브젝트와 같은 발밑 y 순서로 정렬합니다. 위쪽 타격은 아래에 서 있는 공격자의 뒤로 가려질 수 있으며 모든 효과가 맨 위에 그려지지 않습니다. 동시160개 제한과 현재 시야 검사는 유지합니다.

프로필48개는 기본 주민의 정면 중립 프레임에서 어깨 위를 잘라64셀로 만든 `portraits.png`입니다. 얼굴·머리색·성별을 다시 생성하지 않습니다. 주민 목록·개인 상세·시설 직원·직접 배치·계약 후보에 같은 프로필을 사용합니다. 기본 주민 목록의5스탯은 왼쪽부터 힘/민첩/체력/손재주/지능 순서의 색상 숫자만 표시하고 이름은 마우스를 올릴 때 설명합니다.

방어탑 배치에서 주간06~18/야간18~06을 처음부터 선택합니다. `core_expansion_assign_shift`는 빈 슬롯을 먼저 확인하므로 실패하면 원래 일터를 유지합니다. 기존 같은 탑의 근무조 변경 제한은 유지합니다. 방어탑 상세는 주간과 야간을 나누고 프로필·이름·현재 행동·전투 담당을 표시합니다.

습격 경보는 도적/마물/언데드/숲/북방/광신도 문장과 큰 세력명, 적 종류별 그림1개·인원·HP·공격·사거리·공격 주기·속도를 보여줍니다. 같은 종류를 여러 카드로 반복하지 않고 긴 편성은 스크롤합니다. 경보 뒤 화면의 버튼과 지도 입력은 차단하고 확인 버튼으로 경보가 만든 일시정지만 해제합니다.

재난·역병·경제 사건·습격·겨울 식량 안내는 독립된 줄/카드로 쌓습니다. 사건 알림도 실제 글꼴과 줄바꿈 높이를 계산해 그 아래에 배치하므로 고정 좌표에 겹치지 않습니다. 안내 카드를 눌러 뒤쪽 건물을 조작하지 않도록 입력 영역도 맞춥니다.
