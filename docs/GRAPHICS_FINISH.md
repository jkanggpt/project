# 그래픽 마무리: 재료·불빛·구름·물·검수 모드

기존 2D 픽셀 원화의 정체성·실루엣·윤곽·팔레트를 유지하면서 실제 게임의 공용 OpenGL 4.3 렌더러(`castle_gpu`)에 재료 표면, 받침 흙, 다중 지역광, 친선 인물의 야간 등불, 고정 불, 시야 경계 구름, 물의 햇빛 반짝임을 완성했습니다. 게임 규칙·저장 형식·튜토리얼 흐름은 바꾸지 않았습니다. 이전 단계의 이미지 인계는 [이미지 인계](GRAPHICS_FINISH_IMAGE_HANDOFF.md)에 남아 있습니다.

## 실행

| 실행 | 내용 |
|---|---|
| `start-game.cmd` / `castle_game.exe` | 일반 게임 |
| `lighting-review.cmd` / `castle_game.exe --lighting-review` | 실제 게임 렌더러의 조명 검수 장면(저장하지 않음) |
| `benchmark-game.cmd` | 네 해상도 × 밤·낮 검수 장면 측정. RTX 4060이 아니거나 소프트웨어 렌더러면 결과를 받아들이지 않음 |
| `check-graphics.cmd` | 메뉴 → 새 게임·튜토리얼·이어하기·불러오기 → 메뉴 반복과 GPU 자원 수 검사 |

검수 장면은 건물 네 방향(집)·선술집·가마·용광로·마법탑·시장·병영·오두막·저택·풍차·사냥 야영·채집 야영·감시탑, 밭·경작지·과수원·텃밭, 흙길·돌길·포장길, 호수·항구·등대, 돌문과 성벽, 나무·바위, 기본 240명의 밤 군중과 구름 경계를 한 지역에 모읍니다. 실제 `GameSession`이 주민을 움직이며 사용자 저장 폴더 대신 `lighting_review_saves`를 쓰고 저장 명령도 거부합니다.

| 조작 | 동작 |
|---|---|
| `F7` | 밤 → 새벽 → 낮 → 해질녘 |
| `F8` | 진단 보기: 최종 조명 · 알베도(명암 완화) · 법선 · 태양 그림자 · 지역광 차폐 · 물 반사 · 재료(높이·발광·거칠기) · 칸별 광원 수 |
| 방향키 | 태양 방위·고도 |
| 오른쪽 마우스 | 누르는 동안 커서 위치의 시험 횃불 |
| 가운데 마우스·휠 | 이동·정수 배율 |
| `H` / `U` | 도움말 접기 / 게임 UI 숨기기 |

촬영·자동 확인: `--review-phase 0-3 --review-view 0-7 --review-sun 방위 고도 --review-zoom 1-6 --review-clean --crowd n --frames n --screenshot 파일`. 성능: `--review-benchmark 프레임수`.

## 구현

**받침 흙.** 점유 칸 전체를 흙색으로 덮어쓰던 갈색 사각형을 없앴습니다. 점유·풀 제외 표식(지형 칸 16)은 실제 지형·길·물·눈·시야 자료와 분리합니다. 흙은 건물 원화 받침(조명용 기준 체적의 바닥)과 문 앞만 따르며, 잡음으로 흩은 테두리를 화소 디더로 끊어 각진 경계가 생기지 않습니다. 밭은 이랑 원화를 유지하고 바깥 가장자리만 풀어 줍니다(`terrain.fs`의 `footprintWear`, `castle_gpu_footprint`).

**재료 표면.** 354개 시트·7,304칸을 `art/sources/sprite_materials/guides.txt`의 지붕·벽·원추·천막·유기면·인물·선체·지면 지침으로 다시 구웠습니다. 표면 RGBA는 법선과 같은 해상도이며 R 상대 높이, G 발광, B 거칠기, A 틈새 차폐입니다. 기존 여섯 보정 표본의 표면 규약(R·G 16비트 높이, B 발광)은 실험실 전용으로 그대로 두고, 게임은 구운 재료가 있는 시트에서 모든 프레임에 같은 규약을 써서 걷기·회전 중 밝기·모양 규약이 바뀌지 않습니다. 명암 완화는 회전 `.0~.3`을 한 계열로 묶은 색상별 밝기 기준을 공유합니다. 발광은 흰빛에 가까운 불꽃·유리 중심에서만 시작해 2화소 안의 따뜻한 화소로 넓히므로 주황 벽돌·크림색 회벽을 발광으로 오인하지 않습니다. 빈 집·멈춘 일터의 원화 창·화덕 발광은 점등 조건(`game_scene_lit`)으로 끕니다.

**건물 기준점과 그림자.** 73종 × 4방향 수동 기준점(`art/sources/scene_profiles/buildings.inc`)으로 벽·지붕·굴뚝 체적과 창·문·횃불·화덕·마법·등대 광원 위치를 정합니다. 광원은 앞 벽보다 한 화소 밖에서 시작해 벽을 통과하지 않고, 법선은 면 음영만, 높이·차폐 체적은 투사 그림자를 만듭니다. 굴뚝 연기와 창빛은 실제 가동·거주·근무 상태를 따릅니다.

**휴대 등불·고정 불.** 인계 원본 8×4 시트(`carried_lights_padded.png`, `stationary_fires_padded.png`)를 `tools/art/carried_lights.c`가 셀 경계 `round(i×폭/열)`, 알파 128 이진화, 투명과 맞닿은 붉은 후광 제거, 작은 불씨 조각 제거, 받침 띠 중심 고정, 8×8 정수 표본 평균, 채널 8단계로 16화소·24화소 칸에 굽습니다. 칸 기준점과 불꽃 중심은 `game/src/render/fire_atlas.h` 한 곳에 있고 도구 검사와 게임이 함께 씁니다. 주민·일꾼·상인·배 선원은 랜턴(정면·측면·후면 행), 병영·주둔지 복장은 횃불을 듭니다. 걸음 흔들림, 좌우 반전, 뒷모습일 때 몸 뒤 그리기, 해질녘·새벽 서서히 켜짐, 실내·구름 아래 꺼짐을 따르고 광원은 그려진 불꽃 중심에 둡니다. 고정 불은 가마·용광로 입구(작업 중), 문·감시탑·시장 화로와 채집·벌목 야영 모닥불(밤)에만 드물게 둡니다. 다른 건물의 창·문 등불은 원화에 이미 그려져 있으므로 빛만 더합니다.

**다중 지역광.** 전역 가까운 네 개·고정 열여섯 개 한도를 없애고, 화면에 닿는 모든 광원을 16화소 칸 목록으로 묶습니다. 칸 목록은 254개 한도와 넘침 표식을 가지며 넘친 칸은 전체 광원을 순회하므로 광원이 조용히 빠지지 않고 버퍼 크기는 광원 수와 무관하게 묶입니다. 자세한 동적 그림자 예산(16개)은 화면 가운데에 가까운 고정 광원에 주고, 이동 등불은 고정 벽의 간략 차폐를 써서 벽 너머로 새지 않습니다. 첫 네 지면 그림자 캐시는 이동 등불을 제외하고 번호·위치로 키를 만들어 이동 주민이 캐시를 매 프레임 무효화하지 않습니다. 지역광 합에는 부드러운 무릎을 두어 군중 등불이 하얗게 타지 않습니다.

**구름 시야 경계.** 검은 사각형을 지우고 GPU 절차 뭉게구름(`fog.cs`)으로 바꿨습니다. 보이지 않는 칸 바깥으로 지면을 정확히 한 칸 더 그리고, 숨은 칸(그 여유 칸 포함)은 항상 불투명합니다. 보이는 칸 안쪽 가장자리만 구름 덩이 높이에 따라 1~14화소 밀려 들어오고 3~10화소에서 디더로 풀립니다. 크기가 다른 두 층의 지터 덩이와 왜곡 잡음, 왼쪽 위 빛의 볼록면 명암을 쓰며 월드 씨앗·세계 좌표에 고정되어 층마다 다른 속도로 천천히 흐릅니다. 연기·그림자·날씨·효과를 포함한 세계 층 뒤, UI 앞에서 합성합니다. 탐험·선택·인물 시야는 별도 자료로 유지하며 상태 말풍선·구름 아래 불빛·연기는 시야로 거릅니다. 구름 계산이 실패하면 화면 전체를 불투명하게 덮습니다.

**물의 햇빛 반짝임.** 고정 시점의 시선, 햇빛 방향, 움직이는 물결 법선 주변의 세계 고정 미세면(3×1 화소 칸)으로 절제된 반짝임과 짧은 가로 띠를 계산합니다. 그림자 속·흐림·비·눈에서 줄고 밤과 낮은 고도에서는 사라집니다. 물 색·깊이·거품·물결 무늬와 물가 경계는 그대로 둡니다. 물 효과를 끄면 시간도 멈춥니다.

## 한계

- 성능: 클라우드 llvmpipe 실행은 기능 확인입니다. RTX 4060 실제 측정은 `benchmark-game.cmd`로 사용자 장비에서 기록해야 하며 이번 작업에서 새 하드웨어 수치를 만들지 않았습니다.
- Windows: MSVC 전체 빌드·CTest는 이 환경에서 실행하지 못했습니다. MinGW 교차 빌드(코어·콘솔 WERROR)와 바뀐 게임·도구 소스의 MinGW·Clang `-Werror` 구문 컴파일로 대신 확인했습니다. 실제 MSVC 검사는 Windows CI나 사용자 장비에서 필요합니다. `benchmark-game.ps1`도 PowerShell로 실행해 보지 못했습니다.
- 표면 높이·차폐 체적은 2D 원화에서 만든 조명용 근사이며 숨은 입체 형상을 복원한 것이 아닙니다. 창·문 등불이 원화에 그려지지 않은 일부 건물은 빛만 있고 불꽃 그림이 없습니다.
- 상인·배 선원 칸은 자세가 적어 등불 손 위치를 인물 사각형 비율로 정합니다. 좁은 배 선원 그림에서는 아틀라스를 0.75배로 그립니다.
