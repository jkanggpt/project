# 메인 화면

세계 스프라이트 전체의 알베도·법선 확장과 검사 기록은 [SPRITE_MATERIALS.md](SPRITE_MATERIALS.md)에 있습니다. 제목 배경과 새 게임·튜토리얼·불러온 영지는 같은 재료 캐시를 사용합니다.

`docs/PLAN_MAIN_SCREEN_TUTORIAL.md` 5.1의 구현과 검사 기록입니다. Phase 0 병합 커밋 `27054e7`에서 만든 `codex/main-screen` 브랜치에서 작업합니다. PR 대상은 `codex/structure-cleanup`이며 병합은 사용자가 합니다.

## 구현

- 시드 42·평화 난이도의 배경 영지에 공개 건설 API로 막사·우물·텃밭·벌목지를 배치하고 공용 실행기로 초기 건설을 진행합니다. 실제 주민 4명이 움직이며 카메라가 천천히 이동하고 낮밤 색이 부드럽게 바뀝니다. 비활성 창에서는 시뮬레이션과 카메라를 멈춥니다. 특별 이주 전에 배경을 다시 만들어 주민 수를 제한합니다.
- 배경 시야 사본만 밝히며 실제 게임의 탐험 규칙은 바꾸지 않습니다. 새 게임·튜토리얼·불러오기는 기존 세션 교체 경로를 사용하고, 제목으로 돌아오면 배경 세계를 다시 만듭니다. 배경은 자동 저장하지 않습니다.
- 금색 Galmuri 제목과 그림자, 기존 영주관 그림의 문장, 반투명 메뉴를 배치했습니다. 새 원화나 런타임 에셋은 추가하지 않았습니다. 계획에서 허용한 글자 로고·기존 그림 조합이며 기존 매니페스트·재생성 경로·권리 고지가 그대로 적용됩니다.
- 이어하기·새 게임·튜토리얼·불러오기·설정·도움말·제작진·종료를 제공합니다. 마우스 올림, 클릭 소리, 위/아래와 Enter 선택을 지원합니다. 이어하기가 없으면 비활성화하고 새 게임을 선택합니다. 구석에는 버전 1.2.4를 표시합니다.
- 최근 저장은 기존 최근 슬롯 선택 함수와 `core_peek_save`로 확인합니다. 이름·연도·계절·일수·등급·인구를 카드에 표시하며 예비 저장이면 구분합니다. 메뉴 진입과 5초 간격으로 갱신해 저장 파일을 매 프레임 읽지 않습니다. 불러오기 실패와 예비 파일 확인은 기존 경로를 유지합니다.
- 새 게임 창은 시드를 검증하고 임시 `CoreWorld`의 지형을 64×64 미리보기로 축소합니다. 지도 크기는 `core_get_map_size` 결과를 표시합니다. 임시 세계와 지형 배열은 즉시 해제하며 영구 텍스처는 만들지 않습니다. 입력 중에는 0.3초 기다린 뒤 재생성합니다. 빈 초기 시드는 먼저 정해 미리보기와 실제 시작 시드를 맞추며 새 시드 단추도 제공합니다.
- 세 난이도의 설명과 `core_get_difficulty`에서 읽은 시작 주민·자원·습격·자연 사건·공물 수치를 제공합니다. Tab 입력칸 이동, 난이도에서 좌우 선택, Enter 시작을 지원합니다. 게임 중 패널에서 다시 여는 새 게임도 같은 미리보기를 사용합니다.
- 제작진 창에는 CREDITS.md의 그림·Kenney 효과음·Galmuri 글꼴·raylib/GLFW·학생 제공 주민 이름 출처를 표시합니다.
- 제목 메뉴에서 새 게임·튜토리얼·이어하기로 들어갈 때 0.16초 어두워지고 0.28초 밝아집니다. 게임 중 다시 시작할 때는 밝아지는 전환을 적용합니다. 어두워지는 동안 새 게임 창을 취소하면 시작 요청도 함께 취소합니다. 게임에서 제목으로 돌아올 때도 배경 교체를 어두운 전환으로 가립니다. 실패한 시작/불러오기에서도 화면이 다시 밝아져 오류를 읽을 수 있습니다.

## 담당 경계

수정한 실행 파일은 `game/src/ui/main_menu.{h,c}`, `game/src/ui.h`, `game/src/ui/widgets.c`, `panels.c`의 제목·새 게임 함수와 두 case, `main.c`의 제목 초기화·enter_game 연결점, `render/world.c`의 게임 밖 배경 그리기뿐입니다.

미리보기 검사와 반복 경로 검사는 실제 프런트엔드/메뉴 함수를 연결한 일회성 검사 실행 파일로 수행했습니다. 저장 형식이나 테스트 소스를 바꾸지 않았습니다. 코어 할당 수 외에 전체 할당 누수 검사 결과도 아래에 기록합니다.

전체 할당 검사에서는 12회 반복을 ASan/UBSan과 LeakSanitizer로 실행해 오류·누수 없이 종료했습니다. 일반 할당자의 보유 힙은 첫 회 5,006,160바이트에서 5,016,816바이트까지 올라간 뒤 마지막 5회 동일했습니다. 코어 생존 블록은 모든 회차 51개, 정리 뒤 0개였으며 임시 미리보기 세계마다 증가 0개였습니다. Valgrind는 로컬 동적 로더의 디버그 심볼을 찾지 못해 시작하지 못했으므로 통과로 세지 않았습니다.

키보드로 새 게임 창 열기 → Enter 시작 → Esc 일시정지 → 제목 단추로 복귀도 실제 창에서 확인했습니다. 시작과 복귀의 저장은 별도 `ui-saves` 폴더를 사용했습니다.

추가 검사: 임시 세계 생성에서 코어 할당 실패를 72개 위치에 주입한 뒤 생존 블록 증가 0개를 확인했습니다. 비활성 상태에서는 시계·카메라 목표가 유지되고 공용 루프의 화면 중심을 제목용으로 복원하는지, 전환 중 취소와 시작 실패에서 메뉴가 다시 보이는지도 확인했습니다. 이 검사를 포함한 최종 ASan/UBSan·LeakSanitizer 12회 반복도 종료 코드 0, 누수·오류 보고 없음입니다.

메인 화면 구현 소스 `6d6adc8`의 원격 CI에서 Linux 그래픽 빌드·CTest·스크린숏과 MinGW 교차 빌드가 통과했습니다. 긴 소크 작업은 프로젝트를 빌드하기 전 Microsoft 패키지 저장소의 HTTP 403으로 멈췄으며 워크플로 파일은 변경하지 않습니다. Windows는 전체 검사 272/272와 설치·패키지까지 통과했습니다. [소스 검증 실행](https://github.com/jkanggpt/project/actions/runs/45945912606)과 [PR #4의 최신 CI 체크](https://github.com/jkanggpt/project/pull/4/checks)에서 원격 결과를 확인할 수 있습니다. 패키지 서버 오류는 재실행하며 최신 통합 검사는 PR 체크에서 확인합니다.
