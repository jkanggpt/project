# v1.2.1 적용 기록

기준은 학생의 [원본 명세](V1_2_1_SPEC.html)와 [읽기용 본문](V1_2_1_SPEC.md)입니다. 추가 요청을 우선하며 C11/raylib 구성을 유지합니다. 실제 검사 결과는 [QA](V1_2_1_QA.md)에 기록합니다.

## 규칙과 코드

- `expansion_v121.c`: 개인 효율 상한7.5, 실제 근무·중심 거리·이름/성별·거래 처리량의 공통 계산입니다. 하루 실제 근무는 개인별9시간까지 적립합니다.
- `expansion_people.c`: 직무별6시간 잔여를 보존하고 총5.000XP를 가중치로 배분합니다. 성장 상한에 막힌 XP를 재분배하지 않습니다. 의료는 현장 의료진·자격·약초·환자 진행도를, 교육은 학교 최고 지능5/합7·학술원 최고7/합15를 확인합니다. 교육·문화의 기본 보상과 효율 추가분을 구분합니다. 방문 시설은12~21시에 근무해 저녁에도 실제 직원이 서비스를 제공합니다.
- `expansion_economy.c`: 농업은 일한 시점의 사건과 완료 이후 풍요의 룬만 적립하고 수확 때 과거 가뭄을 다시 곱하지 않습니다. 정수 내림 수확, 무인 풍차, 실제 성목 잔량 공유, 조림의 제곱근 효율과 마력수 제외, 수역 공동 어획을 적용합니다. 마법 연구 재료는 실제 가동 시간에 비례하며 연구점에 효율을 적용합니다. 마법 공방의 주변 생산 보너스는 삭제합니다.
- `expansion_animals.c`: 새끼만 직접 구매합니다. 사료→나이→성체 생산→수명 도축→생존 성체 재집계→시설×축종 번식 순서입니다. 생후0일 개체는 다음날부터 먹이를 먹습니다. 한 배치가 들어갈 빈칸이 없으면 번식을 미루며 자리를 만들려고 임의 도축하지 않습니다. 굶주림·피해 사망에는 도축 보상이 없습니다.
- `expansion_commands.c`: 실제 현장 근무 시설의 시야를 공급자 서명으로 캐시합니다. 영주관·연결 도로는 고정 시야이며 합류 전·이탈 주민은 시야를 밝히지 않습니다. 건설은 점유할 모든 칸이 현재 보여야 합니다. 거래 건물은 건설 중·폐허를 포함해 한 곳만 허용합니다. 도로/성문 철거는 완공된 도로 의무 시설의 연결을 보호합니다.
- `expansion_world.c`, `expansion_ecology.c`: 큰 기후 영역이 이어지는 생물군계, 기존24종+환상종6종, 면적별 서식지 목표·생체량·전역360 한도, 환상종 고유 개체·출현일·재출현 대기를 사용합니다. 실제 주민/경비병 타격을 성공한 야생 개체만 하루 동안 방어 표적이 됩니다.
- `expansion_raids.c`, `threat.c`, `combat.c`: 6세력28종의 고정 능력치·계절 가중치·날짜 해금·예산 편성입니다. 첫 두 습격은 기본 유닛3~5명, 이후 기본 편성24명입니다. 가능한 영주관25~40칸 밖의 도달 가능한 비점유·비보호 지점에 출현하고 발견 시에만 알립니다. 두목 버프·공성·망령 벽/문 통과·소환/소유자 사망 정리·치료·둔화·범위 공격·사망 폭발과 처치 보상을 분리했습니다. 공격 세 번째 프레임에 한 번 타격/발사합니다. 적 배열은 동적 증가하며 소환체에24/40명 상한을 두지 않습니다. 실제 할당 실패는 생성 보류입니다.
- `nature.c`, `expansion_prices.c`: 자연 사건1칸·역병·경제 사건을 별도로 진행하고 휴지기·농업 적립·시세 보정을 저장합니다. 번개·비·바람·서리·녹색 안개·입자와 낮은 효과 옵션을 제공합니다. 비·천둥은 C에서 합성합니다. 기존 화살 크기는 유지하며 투사체의 윤곽·궤적·종류별 색과 형태를 구분합니다.

## 추가 요청과 그림

ZIP의 남성162개·여성162개를 가져왔습니다. `M:`/`F:`는 내부 표시이며 화면에서는 제거합니다. 이름의 성별과 저장된 `sex`, `appearance`를 연결합니다. 갈발·금발·흑발·적발·은발·남색 머리의 남녀12외형이며 직업 변경과 무관합니다.

원화15장은 `art/v121`, 전문 프롬프트는 `art/V121_PROMPTS.md`입니다. `castle_v121_art`가 불균등한 행·열을 투명 경계로 분리하고, 수목은 연결 성분으로 나누어20개를 온전히 자릅니다. 적 걷기/공격은 앞·옆·뒤 각각4프레임이며 왼쪽은 반전합니다. 마지막 공격 복귀 자세에는 온전한 준비 자세를 재사용합니다. 새끼4종, 일반 동물9종의 모습에 맞춘 공격, 환상종6종, 계절별 밀밭·관개 수로/스프링클러·울타리 과수원·유리 온실(계절별4방향 추가 시트), 성문4재료×4방향을 패킹합니다.

도로는 황토색 흙길과8이웃 마스크로 바닥 테두리·십자 연결·2×2 내부 모서리를 처리합니다. 교량 난간은 교량이 아닌 물과 맞닿은 변에만 표시합니다. 건물 중심 반경은 중앙 후보 타일의 최단 맨해튼 거리이며 문 접촉·수변 설치·충돌은 실제 점유 모양을 사용합니다. 지정14종 점유 크기와 도로 비용, 일반 이주의 도로 조건 삭제·인원 추첨·새 행복도 기준을 반영합니다.

## 저장과 평가

ABI11/저장v9입니다. 이전 저장을 변환/삭제/덮어쓰지 않고 `saves_v9`에 새로 저장합니다. 실제 노동 잔여·작기 소수 잔여·서비스 처리량·번식·나이·위협·사건·다음 습격·전리품 통계를 직렬화/해시합니다. 진행 중 습격의 저장을 미루는 기존 정책은 유지합니다.

검사 봇은 새 점유 크기에 맞게 성벽 사이 공간을 확보하고 예정 건물의 몸체를 우회해 도로를 놓습니다. 현재 보이는 부지를 우선하며 공개 효율 조회·배치 명령으로 직원을 고릅니다. 정상 평가 도중 자원·시야·등급을 지급하지 않습니다. 강제 성능 영지와 생물420마리 실험은 정상 성장 평가에서 분리합니다.

전투로 패배가 확정되면 틱 사이에도 즉시 멈춥니다. 모든 확장 건물의 붕괴가 통행 격자를 즉시 갱신하며, 불러오기는 시야 캐시만 복구해 탐험 기록을 늘리지 않습니다.
