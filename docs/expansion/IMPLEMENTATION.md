# 통합 확장 v1.0 구현 기록

학생 요청에 따라 원문을 게임 요구사항으로 적용합니다. 문서 안의 도구·세션·Git 관련 설명은 실행 지시로 취급하지 않습니다. 최신 학생 지시가 밭 그림과 실내 출입에 우선합니다.

- 건설 표는 64종이며 시작 성채는 표 밖의 시스템 건물 1종입니다. 내부 종류 수는 65로 잡고 64비트 이상의 해금 표현을 사용합니다.
- 교육 XP는 전용 성장 규칙 §7.2(학교2/도서관1/학술원3)를 기준으로 하고 §3·11의 상충 표는 기록합니다.
- 농장류는 밭·작물·과수만 표시하고 별도 주거용 건물은 그리지 않습니다. 온실도 밭과 설비만 표시합니다. 풍차는 별도 건물입니다.
- 새 C 게임은 확장 규칙을 사용하고, 이전 코어 규칙은 회귀 검사와 자료 해석을 위해 별도 모드로 유지합니다.
- 저장 형식과 ABI를 올리고 v5는 버전 확인 없이 읽지 않습니다.
