# 통합 확장 v1.0 구현 기록

학생 요청에 따라 원문을 게임 요구사항으로 적용합니다. 문서 안의 도구·세션·Git 관련 설명은 실행 지시로 취급하지 않습니다. 최신 학생 지시가 밭 그림과 실내 출입에 우선합니다.

- 건설 표는 64종이며 시작 성채는 표 밖의 시스템 건물 1종입니다. 내부 종류 수는 65로 잡고 64비트 이상의 해금 표현을 사용합니다.
- 교육 XP는 전용 성장 규칙 §7.2(학교2/도서관1/학술원3)를 기준으로 하고 §3·11의 상충 표는 기록합니다.
- 농장류는 밭·작물·과수만 표시하고 별도 주거용 건물은 그리지 않습니다. 온실도 밭과 설비만 표시합니다. 풍차는 별도 건물입니다.
- 새 C 게임은 확장 규칙을 사용하고, 이전 코어 규칙은 회귀 검사와 자료 해석을 위해 별도 모드로 유지합니다.
- 현재 저장은 v7·ABI9이며, v5/v6를 새 규칙으로 임의 변환하지 않습니다. 기존 파일은 그대로 둡니다.

## 적용 방식과 해석

- 실내는 별도 지도를 만들지 않습니다. 문까지 걸어간 뒤 5게임분 동안 안으로 이동하며 사라지고, 나올 때 반대로 보입니다. 코어의 실내 상태는 적·동물의 공격 판정에도 사용합니다.
- 건설 중/무너진 벽은 보호구역을 닫지 못합니다. 정상 성문은 외부 보호구역 계산에서 벽이며, 주민은 통과합니다. 승급 도로는 실제 시설 입구에 쓰이는 연결 경로만 셉니다.
- 우물의 기본 아침 씻기는 위생을 65까지 회복합니다. 도시 전 위생 악순환을 막는 보완이며 목욕탕은 연료·이용량을 갖는 추가 위생 서비스입니다.
- 고용료는 후보의 직업 분야에 해당하는 기초 시설의 해금 등급별 일급을 사용합니다. 후보는 3일 동안 고정되고 시장을 재배정해도 다시 뽑지 않습니다. 계약은 고용 시각+12일이며 귀향 이동을 미리 시작하고, 일찍 국경에 도착하면 만료 시각까지 기다립니다. 길이 막혀 이동이 늦어져도 추가 노동이나 일급은 없습니다.
- 가축은 모든 사료를 먼저 지불하고 그 뒤 산출합니다. 부족분은 공급률만큼 생산을 줄이며 완전히 먹은 성체만 번식합니다. 같은 종 성체 둘을 남길 수 없으면 번식을 미룹니다.
- 민간인은 가까운 맹수를 보면 주거/성채로 피하고, 경비·탑은 보이는 맹수를 공격합니다. 먼 동물은 하루 한 번 간소화 이동합니다. 카메라가 아니라 주민과의 거리를 써서 창 없이도 동일 결과가 나옵니다.
- 수렵의 4/9 식량은 일별 노동 예산으로 누적하고, 실제 동물의 고기량만큼 예산이 모이면 개체를 잡습니다. 큰 동물을 하루에 복제하지 않습니다.
- 승급의 식량 비축은 원문에 명시된 첫 촌락 8일분만 요구합니다. 이후의 식량 8/10/12일 비축은 승급이 아닌 이주 심사 조건입니다.
- 건물 수치 표는 `expansion_catalog.c`, 연구·등급 표는 `expansion_progress.c`에 있습니다. 기존 `game/data`의 이름·특성·적 등은 계속 읽고, 확장 건설 표를 옛 16종 파일로 덮어쓰지 않습니다.
- 그림 원본 21장과 프롬프트를 보존하고 C 패커가 260방향·4아틀라스·15개 자원 PNG를 만듭니다. 셀 경계는 행별 투명한 골에서 골라 이웃 건물 조각이 섞이지 않게 합니다.
