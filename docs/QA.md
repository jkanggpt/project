## 수동 기록

2026-11-16 후속 구도·주민 변경: `native_runtime`은 실제 경로에서 오른쪽→위쪽 방향 전환,
정지·막힌 길에서 방향과 걷기 위상 유지, 외형 8종·왼쪽 반전·뒷면 선택을 검사합니다.
`native_art_assets`는 주민 96프레임 각각의 내용·발밑 정렬과 방향별 걷기 변화 여부도 검사합니다.
`--screen villagers`는 정면/오른쪽/뒷면/왼쪽의 8외형 비교 화면입니다.
건물 지붕·수목 윗면과 주민 측면은 게임 PNG로 확인하고, 같은 주민의 일터 변경·로드 후 외형 유지,
모서리에서 방향 전환, 멈춤·일시정지, 긴 지붕 뒤를 걷는 경우를 수동 확인할 수 있습니다.

2026-11-16 그래픽 교체 검증: `native_art_assets`에서 새 PNG 29개 크기·투명도·빈 이미지 여부,
`native_runtime`에서 주민 1.5타일 높이·건물 지면 기준점·앞뒤 정렬·직업 매핑을 검사했습니다.
Windows 실제 게임 촬영으로 새 그림의 투명 여백·한국어 UI·수관과 지붕 겹침을 확인합니다.
150명/40명 생성 프레임 검사는 최종 평균 32.789 ms·최대 284.149 ms로 60fps 목표 미달입니다.
출력의 마지막 적 0명은 측정 중 전투로 처치된 결과입니다. 실제 PC에서 성능 확인과 추가 최적화가 필요합니다.
수동으로 추가 확인할 항목: 높은 건물 뒤/앞으로 주민이 걸을 때 가림 전환, 건설 미리보기의 실제 점유 테두리,
한 칸 성벽과 성문을 이을 때의 모양, 겨울/가을 수목, 줌 1~6에서 이미지 경계.
