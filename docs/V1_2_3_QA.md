# v1.2.3 검증 기록

2026-11-25 Windows Release 검사입니다. [적용 기록](V1_2_3_IMPLEMENTATION.md)과 [사용자 명세](V1_2_3_SPEC.md)를 함께 참고합니다. 기능 구현, 자동 회귀, 성장 제안 목표, 성능 목표는 각각 판정합니다.

## 빌드·기능 회귀

MSVC와 MinGW 모두 경고를 오류로 처리한 빌드에 성공했습니다. 최종 전체 CTest는 **각각146/146 통과**, 29.93초/26.60초입니다. 로그는 `artifacts/v123/tests_msvc_final.log`, `mingw_final2.log`입니다. MinGW 첫 빌드의 바위 표시 함수 들여쓰기 경고를 수정한 뒤 전체 빌드·검사를 다시 실행했습니다. 이후 변경은 같은 함수의 형식 정리와 설치 문서 목록이며 MSVC도 재빌드했습니다.

- 160 지도·유한 점토·공유 채집, 신규 시설/카탈로그·급수 용량과 우선순위·약초 추가 차감.
- 물물교환29종의 양수 혜택, 창고/재고/횟수/방문/nonce 검증, 중복·실패 요청의 자원 불변, 실제 방문·도보·만료·다음 방문과 저장 왕복.
- 실제 사건과 예보의 일치·조회 RNG 불변, 무인탑 시야·히드라 육지 이관, 추방 하한과 계약/승인 보존.
- 변 인접 수역·교량16마스크·실제 선원 구성/승하선·이동/귀항·저장 상태.
- 수렵 환복 시설 ID 보존·적격 동물 반격 후 사냥 지속·건강35→자기 시설→70 회복·비번 예외.
- 최신 미리보기 소스·바위 표시 감소와 월드 해시 불변, 기존 습격/전투/저장/주민 이동 회귀.

기존 테스트에서 의도한 새160 생성과 옛192 규칙을 구별하도록 구생성 fixture를 명시했습니다. 테스트 개수를 명세의 제안 시나리오438개 통과로 환산하지 않습니다. Linux ASan/UBSan은 실행하지 않았습니다.

콘솔 소크400일×20시드, **1,152,000틱·불변 조건 위반0**입니다. `artifacts/v123/soak400x20.log`. 이 검사는 클래식 규칙이며 확장판의 성장 검증과 구별합니다.

## 지도1000시드·구저장

`castle_v123_worlds 1000`은 같은 시드 구192 생성 결과까지 검산했습니다. **worlds1000·hard_errors0·proposal_target_misses0**, CPU295.072초입니다. 결과는 [1000행 CSV](v123_map_statistics.csv), [요약 JSON](v123_map_summary.json)에 보관합니다.

- 모든 지도:160×160·호수20개·수면2304칸(9%)·작은8/중간10/큰2.
- 모든 지도에서 중간 거리 구간의 생물군계6종 이상, 초원/숲 각각 복수 패치와 최대 패치55% 이하.
- 육상9종 면적 비율이 목표±2%p 안이며, 호수의 육지 간격·시작 안전영역과 자원을 검사합니다.
- 같은 시드 구192의 광종별 실제 매장량 예산을 넘지 않으며, 금/마정석 발견 면적 확대를 검사합니다. 임의 상수 예산으로 비교하지 않습니다.

초기1000지도 결과의 면적 목표 누락121건은 호수의 생물군계별 잠식량을 고려하는 배치로 고쳤습니다. `_initial` 파일은 진단 기록이며 최종 통계에 사용하지 않습니다.

실제 구배포판의 저장9/10 fixture를 읽었습니다. v9는 기존192 타일층의 지형/수역/광상/탐험 보존을 검산했고, v10 회귀는 기존192 크기·신규 점토 초기화·유효 상태 로딩을 검사합니다. 두 버전 모두 기존 지도를 재생성하지 않습니다. 새 저장11의 상인·어선·추방·점토·예보를 왕복하고 해시를 비교합니다. 원본은 읽기만 하며 새 슬롯에 가져옵니다. 수면 히드라는 ID/체력을 유지하고 합법 육지로 옮깁니다. 구저장의 현재 사건은 보존하지만 업그레이드 이후 미래 사건 추첨 스트림은 달라집니다.
