# v1.2.1 최종 검증 기록

2026-11-20 Windows Release 검사를 시작했고2026-11-21(한국시간)에 배포 확인을 마쳤습니다. 규칙과 해석은 [적용 기록](V1_2_1_IMPLEMENTATION.md), 첨부 원문은 [변경 명세](V1_2_1_SPEC.html)입니다.

## 빌드와 회귀

MinGW와 MSVC에서 자체 경고를 오류로 처리한 빌드에 성공했습니다. 공격 중 주기 수정까지 반영한 최종 CTest는 각각129/129(43.48초/121.54초) 통과입니다.

- 신규 회귀는 성별 이름/12외형/저장, 실제6시간의5.000XP, 능률7.5, 사건 중 노동 적립, 수확543/705, 실제 의료진, 마법 재료의 가동 시간 정산, 현재 시야·건물 중심·단일 거래 시설, 가축 나이·사료·번식,28적·동적 소환·중복 드롭 방지를 포함합니다.
- 실제 C 이동·전투 검사에 공격3번째 프레임 타격, 틱 사이 패배 정지, 폐허 통행과 저장 해시, 거래 시설 복구, 공격 중119→120분 경계의 소환/치료를 추가했습니다.
- 거래 교체 격리 검사에서 기존 노점 철거·시장1개 건설·상급 시설 유지·불변식 위반0을 확인했습니다. 이 시험의 준비 자원/도로는 정상 성장 평가와 별개입니다.
- 기존 콘솔 소크400일×20시드(1,152,000틱)는 불변식 위반0으로 통과했습니다. 이 소크의 기존 규칙과 아래 확장판 성장은 구분합니다.

## 그림과 설치본

내장 image_gen으로 원화15장을 제작하고 C 도구로 런타임12아틀라스를 패킹했습니다. 원화/프롬프트는 [그림 기록](../art/README.md), [프롬프트 전문](../art/V121_PROMPTS.md)입니다. 수목20개,12주민 외형의 방향,28적 걷기/공격672셀, 계절별 농장과 온실4방향,4재료 성문,768도로 연결 모양을 확인했습니다. 가축은 실제 개체와 대표 표시를 구분하며 기존 대표 표시 한도를 유지합니다.

MinGW 화면6종, MSVC의 온실 회전·게임·주민 화면을 촬영했고 리소스 오류 로그는 없었습니다. 한글 설치 경로의 오디오 초기화/제목 촬영도 종료0입니다. 원본과 설치본의 리소스·데이터1,011개는 누락/해시 차이0이었습니다. 최종 전투 코드 설치본20일 자동플레이는 인구8·도착497·화살4·저장21회, 저장 전후 해시 `17053130218737720967` 일치로 통과했습니다. 실행 파일 소스/설치 SHA256도 일치합니다.

## 장기 평가 절차

난이도3×시드1~48×최대200일이며 패배하면 해당 판을 종료합니다. 공개 명령으로 건설·배치·철거·수리하며 정상 평가에 자원·시야·등급을 지급하지 않습니다. 일별 상태와 이주/승급/서식지/30종 개체/시세/허브, 퇴근 전 실제 노동·가축 개체·주민 목표/좌표·소환/전리품 CSV를 남깁니다.

최종 실행은 `artifacts/v121/quality_final`입니다. 고정 실행 파일SHA256은 `2AEEED11D0EEE3DF6324DE5F50100B907B3F060DD97B4961AF392BF11F16AC31`, 게임 코드 기준은 로컬 커밋 `c990e23`입니다. 144/144판이 완료됐고9개 평가 프로세스 모두 종료0입니다. 실행 오류0, 저장144/144 해시 일치이며 습격 중 저장 생략은0판입니다. [144행 결과CSV](v121_balance_results.csv)를 보관합니다. 야생 최대360, 서식지 개수/생체량 상한 초과 관측0입니다. 실제 소환506회·로그에서 관측한 동시 소환체 최대5명이며 할당 실패로 보류한 소환은0회입니다. 보통 시드2의200일 재실행도 종료 인구16·촌락·해시 `661990744508199166` 등 전체 종료 요약이 동일했습니다.

수정 전 중단한 `final_balance`69판과 `final_balance_v2`127판은 최종 통계에 섞지 않습니다. 저장 가능한 판만 해시를 비교하고 진행 중 습격은 기존 저장 금지 정책에 따라 생략합니다. 일별 인구·등급의 관측과 종료 요약은 실제 모든 순간의 최댓값을 뜻하지 않습니다.

## 배포와 재현

저장v9/ABI11이며 v8 이하는 새 게임이 필요합니다. 기존 저장은 보존하고 새 저장 폴더를 사용합니다. 배포 폴더는 `artifacts/MagicCastle-v1.2.1`, ZIP은 `artifacts/MagicCastle-v1.2.1-Windows.zip`입니다. 실행 파일 의존성은 Windows 기본 SHELL32/WINMM/KERNEL32/USER32/GDI32만 확인했습니다. Godot/.NET/Python 설치는 필요하지 않습니다.

프로젝트 루트의 빌드된 C 도구로 다시 검사할 수 있습니다.

```text
castle_expansion_balance --days 200 --seeds 48 --data game/data --out artifacts/expansion/v121
castle_v121_art --check game/assets/expansion
castle_game --stress-probe --stress-animals 360 --no-audio
castle_game --stress-probe --stress-animals 420 --no-audio
```

임시 R:가 이 저장소 대상이며 사용 프로세스가 없음을 확인하고 해제했습니다. 해제 후 한글 설치 경로에서20일 스모크·저장21회·해시 `17053130218737720967` 일치, 실제 게임 촬영 종료0·리소스 오류0을 재확인했습니다. 배포본은 임시 드라이브에 의존하지 않습니다.
