# v1.2.1 검증 기록 — 진행 중

2026-11-20 Windows 로컬에서 검사하고 있으며 아직 최종 결과가 아닙니다.

- MinGW Release 경고 오류 빌드 성공. MSVC Release도 별도로 검사 중입니다.
- 이전 전체 CTest123/123 통과 후 작기543/705·마법 가동비·실제 의료진·새 습격 타격 프레임·그림 검사를 추가했습니다. 새 집중 검사11/11이 통과했으며 최종 전체 검사를 남겼습니다.
- 봇 수정 중간 평화 시드8/120일은 첫 폐쇄37일·최대 보호393칸·보호 주민10명·실행 오류0이었습니다. 이후 습격 출현을25~40칸으로 조정했으므로 이 중간 결과를 최종 밸런스로 인용하지 않습니다.
- 새 원화15장·런타임12아틀라스는 C 패킹과 픽셀 검사 대상입니다. 수목20개와 방향별 습격 그림을 시각 확인했습니다.
- 최종3난이도×48시드×200일·저장 왕복·GUI·정상360/과부하420 성능·배포본 확인을 이 문서에 갱신합니다.
- Linux ASan/UBSan과 사람의 장기 수동 플레이는 이 Windows 자동 검사에 포함하지 않습니다.
