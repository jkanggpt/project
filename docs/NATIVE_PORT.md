# C 전환 기록 — 2026-11-14

학생 요청에 따라 Godot/C# 실행 계층을 제거하고 C11 + raylib 5.5로 전환했습니다.
기존 명세의 Godot/.NET 필수 조건보다 이 변경 요청이 우선합니다.

## 간소화·제외

- Godot의 노드·테마·에디터 대신 즉시 모드 C UI를 사용합니다. 이전 화면과 픽셀 단위로 같지는 않습니다.
- 경로는 상하좌우 4방향 A*입니다. 대각선 이동과 Godot 전용 프레임 예산 처리는 제외했습니다.
- 파티클·피격 반짝임·화면 흔들기·생산량 떠오름·일부 상태 말풍선은 간소화했습니다. 핵심 상태는 검사창·알림으로 확인합니다.
- Python 그림 합성기 재생성 기능은 제외하고 생성된 PNG와 원본 Kenney 팩을 유지했습니다.
- 한국어 IME의 조합 상태를 별도 표시하는 입력창은 제외했습니다. 완성 문자와 UTF-8 붙여넣기를 사용합니다.
- 원래 없던 배경음악은 추가하지 않았습니다.
- CMake, CI YAML, PowerShell은 빌드 도구 설정이므로 유지합니다. 게임·밸런스 도구의 실행 코드는 C입니다.

## 호환성과 소유권

정의·리소스 키·API ABI 8·세이브 v5를 유지합니다. 게임은 정적 코어를 연결하며 P/Invoke와 DLL 탐색을 사용하지 않습니다.
코어 상태는 공개 명령·보고로만 바꿉니다. 연속 위치·경로·적의 임시 체력은 GameSession에 둡니다.
습격 중 저장 거절·원자적 저장·백업·손상 검사·로드 실패 시 기존 월드 유지 정책을 보존합니다.

Windows 한글 경로는 UTF-16 변환으로 처리합니다.
PNG·TTF·OGG는 UTF-8 파일 래퍼로 읽어 raylib 메모리 로더에 넘깁니다.
기존 사용자의 세이브를 삭제·이동하지 않습니다. 새 저장 위치와 기존 v5 사용법은 README를 참고하세요.

## 의존성

raylib 5.5 공식 태그 아카이브 SHA-256:
`aea98ecf5bc5c5e0b789a76de0083a21a70457050ea4cc2aec7566935f5e258e`.

설치된 raylib를 먼저 찾고 없으면 CMake FetchContent로 받습니다.
오프라인에서는 `build/deps/raylib-5.5.tar.gz` 또는 `FETCHCONTENT_SOURCE_DIR_RAYLIB`를 사용합니다.
외부 코드는 빌드 캐시에만 두며 학생 코드로 표시하지 않습니다.
