# v1.2.3 구현 기록

2026-11-24~25, C11 코어와 raylib 실행판. 기준은 사용자가 첨부한 v1.2.3 상세 명세입니다. 보관 원문은 V1_2_3_SPEC.html, 읽기용 추출본은 V1_2_3_SPEC.md입니다. 원문의 제안 수치·성장 목표와 실제 검증 결과는 V1_2_3_QA.md에서 구별합니다.

- 상인은 기존 주민과 같은 화풍의 청색·적색 천, 금색 장식 여행복입니다. 원문의 흰 의상은 사용하지 않습니다.
- 추가 유틸리티 교환 U09~U16을 포함해 29종 전부 상대혜택이 양수입니다.
- 11월 25일 지시에 따라 직종 분류 버튼은 기본 UI 색을 유지합니다. 카드만 해금 등급별 색을 사용합니다.

## 지도와 자원

- 확장 규칙의 새 지도만 160×160입니다. 기존 192 지도와 클래식 96 지도는 잘리거나 재생성되지 않습니다.
- 초원·숲 등 육상 생물군계는 여러 큰 패치로 배치합니다. 토지 면적 목표를 고려해 호수가 특정 생물군계만 잠식하지 않게 배치합니다.
- 독립 호수 20곳, 작은 호수 8×45칸·중간 10×130칸·큰 2×322칸, 총 2,304칸입니다. 시작 안전 영역과 초기 자원을 보호합니다.
- 같은 시드의 구 192 생성 결과를 별도로 계산해 광종별 실제 매장량을 예산으로 사용합니다. 금·마정석 등의 양을 늘리지 않고 더 넓게 분산합니다. 돌의 지표층과 다른 광종은 독립입니다.
- 토질별 초기 점토는 유한합니다. 호숫가 맨해튼 거리 1칸 1.4배, 2칸 1.2배이며 중첩하지 않습니다. 현재·초기 재고와 해안 보정은 저장됩니다.
- 채토장은 반경 4의 점토를 기준 8개/일로, 채집장은 반경 3의 같은 점토를 공유합니다. 실제 노동과 남은 창고 공간만큼 차감합니다. 점토가 없으면 채집의 해당 추첨은 식량·약초로 다시 분배합니다.
- 토양 흔적은 잔량 비율에 따라 옅어지고, 지형 툴팁과 채토장 검사창에서 재고를 확인할 수 있습니다.
- 광맥 표시 바위는 위치 해시로 드문 지점과 4×4 구역별 대표 지점을 선택합니다. 이 과정은 월드 상태·난수·재고를 수정하지 않습니다.

급수는 집 중심을 기준으로 가까운 시설 하나를 선택하고, 같은 거리면 급수탑·낮은 ID 순입니다. 우물은 기존 18명·반경8을 유지합니다. 급수탑 보너스는 중첩하지 않으며 자연 위생 감소를 포함하면 +1/일입니다. 빈집의 급수 여유도 이주 심사에 사용합니다.

미술관은 실제 근무·능률을 이용해 관람 크레딧을 쌓고 하루 최대 45명을 제한합니다. 1인 기준15명, 2인 기준30명이며 7시간 운영에 맞춰 정규화합니다. 같은 날 다른 문화시설과 중복 방문 혜택을 얻지 않습니다.

치료 완료에는 치료소 약초3, 병원5가 필요합니다. 건강35 이하/중상 +1, 역병 감염 +1을 가산합니다. 전량이 있을 때만 완료 차감하며 치료 방식·근무 자격은 유지합니다.

무인 방어탑 여섯 종류는 기본 반경2 시야를 갖고, 실제 직원의 기존 시야·공격 규칙은 유지합니다. 무인 자동 사격은 없습니다.

수렵은 적격 동물 반격 때문에 일반 피난으로 덮이지 않게 합니다. 야영지는 생물량4 이하·반경8, 수렵기지는 반경15에서 사냥합니다. 건강35 이하는 자기 시설로 돌아와70까지 회복합니다. 복귀 길이 실제로 막힌 경우에는 이유를 알리고 가까운 비상 대피지로 갑니다. 사냥 대상 번호가 환복 시설 번호를 덮어쓰지 않습니다.

주거 검사창은 실제 home_id가 연결된 주민을 활동과 무관하게 보여 줍니다. 초상·개인번호·일터·건강·행복·기분·위생·식수가 있으며 클릭하면 프로필과 원래 집으로 돌아가기 버튼이 나옵니다.

추방은 확인창과 코어 재심사를 거칩니다. 이미 떠날 인원까지 제외한 영구 주민8명을 보호하며 계약 주민은 이 하한에 포함하지 않습니다. 승인 사유·시각을 저장하고 실제 걸어서 이탈합니다. 길이 막혀도 즉시 삭제하지 않으며 배에 탄 사람은 먼저 귀항·하선합니다.

히드라의 수영은0입니다. 기존 저장의 수면 히드라는 같은 ID·체력으로 가장 가까운 합법 육지에 이관합니다.

## 상인·예보·어선

상인은 주민·고용·금화 시장과 독립된 NPC입니다. 촌락 승급 뒤 첫 목표 도착4~8일, 다음 방문 목표는 직전 도착 뒤12~24일입니다. 경계→영주관→경계로 실제 길을 따라 이동하고, 도착한 순간부터432틱 동안 거래합니다. 인구·소비·전투·탐험 시야에 포함하지 않습니다. 경로가 막히면 기다렸다 다시 탐색합니다.

등급별 제안은3/4/5/5/6개, 마정석 제안은1/1/2/2/3개입니다. 방문 당시 등급을 고정하고 중복 레시피를 뽑지 않습니다. 재고·수령 창고·잔여 횟수·방문 번호·요청 nonce를 먼저 검사한 뒤 한 번에 교환합니다. 실패·중복 요청은 자원을 바꾸지 않습니다. 저장 후 횟수·만료 시각·nonce가 복원됩니다.

상대혜택 = 수령 물품의 기본 BUY 가치 / 지불 물품의 기본 SELL 가치 − 1입니다. 계절·현재 시세로 제안의 이익을 부풀리지 않습니다. 전체 수치는 v123_barter_recipes.csv에 있습니다.

자연·역병·경제 사건은 시드·날짜별 독립 계획 스트림을 사용합니다. 실제 사건과 천문대는 같은 계획 함수를 쓰고, 예보는 상태 복사본을 계산하므로 게임 RNG를 소비하거나 사건 일정을 바꾸지 않습니다. 실제 근무 F에 따라12~48일, 12일 구간별 신뢰90/80/70/60%이며 습격은 예보하지 않습니다. 현재 사건·쿨다운은 구세이브에서 보존됩니다. 업그레이드 이후 미래 추첨 스트림은 구버전과 다릅니다.

항구 직원은 실제 출근 후 2인승 어선에 탑니다. 1/2/3/4명은1척1인/1척2인/2척2+1인/2척2+2인으로 구성하고, 늦게 합류하면 귀항해 재편합니다. 선체4방향과 기존 주민 상반신이 함께 회전합니다. 실제0.55칸/10분, 6개 경유점을 순환하며 퇴근·재배치·질병·추방에는 귀항 후 하선합니다. 하선 때 화면 배우도 실제 부두 좌표로 동기화합니다. 항구 파괴 시 가까운 안전한 해안으로 내립니다.

낚시터·항구 모두 변으로 맞닿은 수역만 사용합니다. 접촉 칸 수·수역 면적·ID 순으로 수역을 고릅니다. 어획량은 기존 공동 수역 상한을 공유하고, 배 길이 막혔다고 생산을 복제하거나 없애지 않습니다.

교량은 육지에도 깔 수 있습니다. 수면의 water_id·어획 면적은 유지합니다. N/E/S/W16마스크로 자동 난간을 만들며, 바닥→뒤 난간→주민·배→앞 난간 순서로 그립니다. 어선 길찾기는 육지·교량·벽·건물로 들어가지 않습니다.

## 코드·아트·저장 경계

- expansion_v123_world.c: 새 생물군계·호수·구시드 광맥 예산·점토층.
- expansion_v123_rules.c: 수변·급수·점토 채취·의료·추방·수렵·구저장 이관.
- expansion_v123_trade.c: 상인 상태·도보 경로·제안·원자적 교환.
- expansion_v123_boats.c: 승하선·수면 항로·귀항·구성 재편.
- expansion_v123_services.c: 실제 사건 계획·복제 예보·서비스 갱신.
- game/src/v123_ui.c: 상인·가구·급수·의료·천문대 검사창.
- tools/pack_v123_art.c: 원화13장→적용 PNG23개, 셀·알파 검증.
- art/V123_PROMPTS.json과 V123_MANIFEST.json: 생성 요청·참조·치수·SHA256.

새 시설은 기존0~65를 유지하고66~69에 추가했습니다. ABI13, 저장11입니다. 저장9/10/11을 읽고 새 저장은 v11 폴더에 씁니다. 메뉴에서 v9/v10 원본을 별도 선택하여 빈 v11 슬롯으로 가져오므로 옛 원본을 덮어쓰지 않습니다.

추가 상태는 명시적인 정수 필드 목록으로 직렬화합니다. 점토 초기화 여부·초기/현재량, 상인 방문/횟수/nonce, 승선자·배 위치·항로, 추방 승인과 예보 캐시를 해시에도 포함합니다. NPC·어선 길찾기는 물류용 거리 배열과 별도 임시 버퍼를 사용합니다.

농업·온실·성문·성벽·도로 등 기존 아틀라스, 자원15종, 공사·폐허 표현, 주민48종은 실제 최신 렌더 자산을 재사용합니다. 천문대는 방향4×주야2×관측8=64프레임이고 실제 자격 직원 근무 때만 움직입니다. 상인은4방향×(걷기4+대기2), 어선은4방향×4프레임입니다.
