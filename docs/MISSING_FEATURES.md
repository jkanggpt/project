# 확인된 한계와 미검증 항목

이번 변경은 현행 동작을 보존하는 구조 정리와 사용자가 확정한 콘솔 규칙 통합입니다. 기존 성장 수치를 낮추거나 새 밸런스 기능을 추가하지 않습니다.

- 기준144판은 평화44/48·보통36/48·혹독1/48 생존, 도시0/144입니다. 성장 제안 목표 미달을 유지·기록하며 정리 성공과 구분합니다.
- 기준 생태 관측에서 지역 생물량 초과가2회 있었습니다. 원인 확정과 밸런스 변경은 별도 과제입니다.
- 전후6쌍과 동일 파일3쌍 대조에서 큰 환경 편차를 확인했습니다. 합산·짝별 중앙값의 지속5% 악화는 재현되지 않았지만 안정60FPS는 미달입니다. 작은 성능 개선을 확정하지 않습니다.
- Linux ASan/Clang, 사람의30분 연속 플레이, 도시30판,32어선과 최대 회전 건물을 동시에 배치한 부하는 이번 환경에서 검증되지 않았습니다.
- 공개 C 헤더는 C++11에서 두 포함 순서로 링크 검증했습니다. 기존 공개 필드 requires는 C++20 예약어이므로 C++20 헤더 호환은 지원 확인 범위가 아닙니다. C11 실행과 ABI14는 유지합니다.
- 그래픽 마무리: RTX 4060 실제 성능(`benchmark-game.cmd`), Windows MSVC 전체 빌드·CTest, `benchmark-game.ps1` 실행, 354개 시트 모든 칸의 사람 시각 승인은 이번 환경에서 확인하지 못했습니다. 상세는 GRAPHICS_FINISH.md 한계 절입니다.
