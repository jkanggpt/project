# 저장 형식

현재 스키마 ID는 14, 공개 ABI는 15입니다. 릴리스 버전과 독립된 기술 식별자입니다. 현행 스키마만 읽으며 과거 형식의 변환·다른 저장 폴더 검색은 하지 않습니다. 지원하지 않는 헤더는 “지원하지 않는 이전 저장 형식입니다. 새 게임을 시작해 주세요.”로 안내하고 기존 월드와 파일을 유지합니다.

파일은 UTF-8 텍스트입니다. MAGICCASTLE_SAVE 헤더, meta/clock/rng/resources/ledger/map/buildings/villagers/nature/market/merchant/threat/research/progress/expansion 섹션, end 및 CRC32 꼬리말로 구성합니다. 섹션 중복·필수 키 누락·ID 연결 오류·잘린 레코드·범위 위반·CRC 불일치는 거부합니다. 행 길이는65536바이트로 제한합니다. 포인터는 ID로 직렬화하고 임시 월드를 완전히 검증한 뒤에만 채택합니다.

현재 상태 테이블은 state/tile/building/villager/animal/boat/raid/enemy/projectile/candidate/archive 레코드로 통합합니다. 날짜·난수·분수 자원·노동·숙련·수확 미수령·상인 nonce·예보·입출항·습격 접근/퇴각·실제 위치를 보존합니다. 격자 수정 번호도 보존하여 창고 경로 캐시의 미래 갱신을 동일하게 유지합니다. ruleset=1은 단일 현행 모델의 고정 마커입니다. 다른 게임 모드를 고르는 값으로 사용하지 않습니다.

스키마 14는 `[progress]` 섹션에 튜토리얼 안내의 필수 키 `guide=켜짐,단계,예약`을 더했습니다 (켜짐 0/1, 단계 0~14, 예약 0, 꺼져 있으면 단계 0). 일반 게임은 `guide=0,0,0`입니다. 스키마 13 세이브는 다른 이전 형식처럼 거절합니다. 자세한 내용은 [TUTORIAL.md](TUTORIAL.md).

불러올 때 동물의 지역(region)은 저장된 값을 그대로 씁니다. 지역은 게임 중 하루에 한 번만 위치를 따라가므로, 위치로 다시 정하면 저장 직전과 다른 상태가 됩니다.

쓰기 순서는 같은 폴더의 .tmp 생성 → 본문과 CRC 기록 → fflush/닫기 → 유효한 같은 형식의 본 파일을 .bak으로 복사 → 원자 교체입니다. 실패하면 원본을 보존하며 .bak은 같은 스키마의 장애 복구용입니다. 다른 스키마의 파일을 자동 변환하지 않습니다.

일반 게임은 사용자 데이터의 saves/slot*.sav, 자동 검사는 saves_automated 또는 명시된 별도 경로를 사용합니다. 코어는 접근·공격·퇴각 단계를 직렬화합니다. 실행기 체크포인트가 실제 적·투사체 상태를 함께 보존합니다. 사용자 저장을 정리 스크립트의 삭제 대상으로 삼지 않습니다.
