# v1.1.1 적용 기록

기준 문서는 [통합 명세](V1_1_1_SPEC.md)입니다. [v1.1](V1_1_REFERENCE.md)은 변경 경위를 확인하는 참고 자료이며, 수치·방향 수·포획·스폰 상한이 충돌하면 v1.1.1을 적용합니다. 문서 속 작업 절차는 게임 규칙과 구별했습니다. 학생의 지시에 따라 원격 푸시 없이 로컬 커밋으로 정리합니다.

## 학생의 추가 요청

- 도로는 투명 여백이 없는 흙·돌·다리 전용 타일로 한 칸 전체를 채웁니다.
- 건물의 제한된 표시 폭을 유지하고 높이를 원본 비율에 가깝게 줄였습니다. 높이의 하한은 점유 타일 높이입니다. 밭은 점유 사각형을 그대로 씁니다.
- 합류 전·이탈 중 주민은 시야 계산에서 제외합니다. 미발견 영역 위에서도 그림은 표시하고, 합류한 뒤부터 탐험에 기여합니다. 계약 주민의 입국에도 적용합니다.
- 수목은 자작나무·소나무·참나무·마력수의 기존 성장 기간을 유지합니다. 원화의 행과 기존 수종 ID를 명시적으로 연결해 서로 뒤바뀌지 않게 했습니다. 묘목/유목/성목 12개, 가을/겨울 성목 8개입니다.
- 자원 표시 순서는 금화·마정석·식량·원목·목재·돌·약초·가죽·점토·벽돌·석탄·철광석·철괴·금광석·금괴입니다. 저장 enum은 재배열하지 않았습니다.
- 건설 선택은 v1.0 표의 순서를 사용합니다. 주거는 막사·오두막·주택·저택입니다.
- 생물군계 경계와 호숫가에는 이웃별 연결 마스크를 적용합니다. 물가의 대부분은 물이며 가장자리에 이웃 생물군계가 섞입니다. 호수 판정은 그대로 유지하고 냉수·온수 그림을 구별합니다.

## 저장·진단·성능

- 저장 v8 / ABI 10입니다. 3×3 영주관이 포함된 v7 이하 저장은 명시적인 버전 오류로 거절합니다. 건물이나 저장 파일을 지우는 마이그레이션은 하지 않습니다.
- 기본 사용자 저장 경로는 `saves_v8`로 분리했습니다. 기존 `saves` 폴더를 자동 저장으로 덮어쓰지 않습니다. 자동 검사는 별도 폴더를 사용합니다.
- 신규 지속 상태는 명시적 정수 직렬화·해시에 포함합니다. 서식지 지리·수역 연결·온도는 동일 지도에서 재계산하고, 생성 시 정한 생체량 수용량은 저장합니다.
- `castle_expansion_balance`는 일별 명세 CSV와 `.events.csv`를 출력합니다. 일별 행은 06시 정산 뒤 기록합니다. 이동·농업 근무·이주·이탈·사망 집계는 직전 06시부터의 구간입니다. 허브 방문은 누적값입니다. 무창 검사에서는 `render_ms=0`이며 그래픽 측정치로 해석하지 않습니다.
- `.immigration`, `.promotion`, `.habitats`, `.people`, `.prices`, `.hubs` CSV를 함께 기록합니다. 승급은 부족한 조건을 각각 구분하고, 서식지는 수용량·개체·최근 사냥·압력과 전역 스폰 거절 집계를 기록합니다. 종별 야생/가축 수와 부상 주민·누적 사망도 비교할 수 있습니다.
- 상세 CSV는 06시 상태 표본입니다. 가격 파일의 거래량은 당일 순거래량이며 개별 주문 감사 장부가 아닙니다. 이주 직전 추정 인구 열은 사망·계약 귀환과 같은 날 겹치면 실제 직전 인구와 다를 수 있어 이름에 `estimate`를 붙였습니다. 개별 사망·이탈은 사건 파일로 추적합니다.
- 주민 목록 상단에는 일반/특별/보충 이주 상태·최근 합류·다음 심사·빈집·물·도로·식량·행복도와 전체 거절 사유 툴팁을 표시합니다. 주민 행과 검사창은 행복도와 기분을 별도로 표시합니다.
- `.immigration`, `.promotion`, `.habitats`, `.people`, `.prices`, `.hubs` CSV를 함께 기록합니다. 승급은 부족한 조건을 각각 구분하고, 서식지는 수용량·개체·최근 사냥·압력과 전역 스폰 거절 집계를 기록합니다. 종별 야생/가축 수와 부상 주민·누적 사망도 비교할 수 있습니다.
- 상세 CSV는 06시 상태 표본입니다. 가격 파일의 거래량은 당일 순거래량이며 개별 주문 감사 장부가 아닙니다. 이주 직전 추정 인구 열은 사망·계약 귀환과 같은 날 겹치면 실제 직전 인구와 다를 수 있어 이름에 `estimate`를 붙였습니다. 개별 사망·이탈은 사건 파일로 추적합니다.
- 주민 목록 상단에는 일반/특별/보충 이주 상태·최근 합류·다음 심사·빈집·물·도로·식량·행복도와 전체 거절 사유 툴팁을 표시합니다. 주민 행과 검사창은 행복도와 기분을 별도로 표시합니다.
- 허브의 `saved_travel_ticks`는 선택 경로와 영주관 경로 비용 차이에 대한 진단 추정치입니다. 생산량에 별도 보너스를 더하지 않습니다.
- `castle_game --stress-probe --no-audio`는 120프레임 준비 후 600프레임을 측정합니다. 프레임 제한·수직동기화를 끄고 시뮬레이션은 프레임당 1/60초 진행합니다. 평균/p95/p99/최대와 시뮬레이션·렌더 시간, 검사 구간의 최소 주민·적·야생 수를 출력합니다.
- `--stress-animals 300`은 별도 디버그 과부하 조건입니다. 일반 생태계의 스폰 상한은 180입니다. 코어의 전체 동물 버퍼는 가축과 디버그 개체를 포함해 512칸입니다.

최종 빌드·회귀·장기 밸런스·성능 결과는 [검증 기록](V1_1_1_QA.md)에 정리합니다. 검증 실패를 숨기기 위해 승급 요구치를 낮추거나 봇에 자원을 지급하지 않습니다.
