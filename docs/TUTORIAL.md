# 튜토리얼

메인 화면의 **튜토리얼** 단추로 시작하는 안내 게임입니다. 단계마다 할 일을 알려 주고, 해낸 것을 C 코어가 확인하면 다음 단계로 넘어갑니다. 계획과 파일 담당은 [PLAN_MAIN_SCREEN_TUTORIAL.md](PLAN_MAIN_SCREEN_TUTORIAL.md) 5.2절입니다.

## 플레이어가 보는 것

- **튜토리얼 게임**: 성채 이름 "튜토리얼 영지", 지도 시드 42, 평화 난이도. 새 게임 창에 적어 둔 이름·시드·난이도는 바뀌지 않습니다.
- **안내 창** (왼쪽 아래): 조언자 초상화, 단계 제목과 설명, "n / 14", 진행 표시(예: 연결 도로 6 / 10), "다음"(정보 단계) 또는 "해내면 저절로 넘어갑니다"(행동 단계), "건너뛰기"(한 번 더 물어본 뒤 안내를 끔).
- **강조**: 할 일이 있는 단추·건설 분류 탭·건물 카드에 금색 테두리가 깜빡입니다. 지을 자리는 지도에 초록 칸으로, 눌러 볼 건물은 금색 칸으로, 도로는 시작 칸(초록)과 이을 입구(금색)로 표시합니다.
- **시간**: 정보 단계를 읽는 동안에는 시간이 멈추고("시간 다루기" 단계만 예외: 직접 멈추고 배속을 바꿔 보도록), 행동 단계로 넘어가면 원래 배속으로 돌아갑니다.
- **습격**: 방어 단계를 마칠 때까지 습격이 오지 않습니다 (차례가 와도 하루씩 미룸).
- 오른쪽 "성채 안내"는 튜토리얼 중이라는 안내로 바뀌고, "처음 목표" 5개는 그대로 함께 채워집니다.
- 저장하고 불러오면 같은 단계에서 이어집니다. 콘솔판의 "상태 보기"에도 지금 단계가 나옵니다.

## 단계

| # | 단계 | 종류 | 넘어가는 조건 | 강조 |
|---:|---|---|---|---|
| 1 | 환영 | 정보 | "다음" | — |
| 2 | 화면 움직이기 | 정보 | "다음" 또는 화면을 움직이거나 확대 | — |
| 3 | 시간 다루기 | 정보 | "다음" | 일시정지·배속 단추 |
| 4 | 텃밭 짓기 | 행동 | 텃밭을 놓음 (짓는 중 포함) | 농업 탭 → 텃밭 카드 → 권하는 자리 |
| 5 | 막사 짓기 | 행동 | 막사를 놓음 | 주거 탭 → 막사 카드 → 자리 |
| 6 | 우물과 물 | 정보 | "다음" | 처음부터 있는 우물 |
| 7 | 벌목지 짓기 | 행동 | 벌목지를 놓음 | 임업 탭 → 벌목지 카드 → 숲 가까운 자리 |
| 8 | 일꾼 직접 보내기 | 행동 | 주민을 일터에 직접 배치 | 텃밭·벌목지 중 다 지은 것 |
| 9 | 도로 잇기 | 행동 | 연결 도로 10칸 | 도로 탭 → 흙길, 영주관 문 앞과 이을 입구 |
| 10 | 자원과 장부 | 정보 | "다음" | 위쪽 자원 숫자 |
| 11 | 방어 준비 | 행동 | 초소와 목책을 놓음 | 방어탑 탭 → 초소, 다음은 성벽·성문 탭 → 목책 |
| 12 | 영지 창 | 정보 | "다음" | "영지" 단추 |
| 13 | 촌락으로 승급 | 행동 | 등급이 촌락이 됨 | "영지" 단추, 진행: 영구 주민 n / 8 |
| 14 | 튜토리얼 완료 | 정보 | "다음" → 안내 끝 | — |

새 게임은 영주관 옆에 우물이 이미 있으므로 우물은 짓지 않고 설명만 합니다. **연결 도로**는 영주관 문에서 다 지은 건물의 입구까지 이어진 도로만 셉니다 (`core/src/buildings/commands.c`). 그래서 도로 단계는 아직 이어지지 않은 건물 가운데 영주관 문에서 가장 먼 것의 입구를 표시합니다.

## 만든 방법

### C 코어 — `core/src/common/tutorial.c`, `core/src/tutorial.h`

- **단계 표 `GUIDE_STEPS`**: 한 줄이 한 단계입니다. 제목·설명(한국어), 종류(정보/행동), 시간 멈춤 여부, 강조 대상, 그리고 함수 포인터 네 개를 가집니다.
  - `done`: 행동 단계를 해냈는가 (예: `placed_garden`, `roads_connected`)
  - `progress`: 진행 표시 (예: 연결 도로 수 / 10)
  - `build_type`: 지을 건물을 그때그때 정함 (방어 단계: 초소가 없으면 초소, 있으면 목책)
  - `building`: 눌러 볼 건물을 고름 (우물, 일꾼을 보낼 일터)
- **상태 `GuideState`** (`World.guide`): 켜짐, 단계, 예약 칸은 저장합니다. 권하는 자리는 저장하지 않는 캐시이며 단계·건물 종류·비용 격자 번호(`grid.cost_rev`)가 바뀔 때만 다시 찾습니다 (배치 검사가 길찾기를 하므로 매 프레임 찾지 않음).
- **권하는 자리**: 영주관 중심에서 3~16칸 고리를 안쪽부터 시계 방향으로 돌며 배치 검사(`expansion_place_check`)를 통과하는 첫 자리. 자원이 모자란 것은 괜찮습니다.
- **진행**: 매 틱(`world_step`)과 `core_guide_view`에서 `guide_tick`이 해낸 행동 단계를 넘깁니다. 정보 단계는 `core_guide_next`로만 넘어갑니다.
- **습격**: `combat/raids.c`가 습격 차례에 `guide_holds_raids`를 묻고, 방어 단계 전이면 하루 미룹니다. 난수를 쓰지 않으므로 일반 게임의 결과는 그대로입니다.
- **해시**: 상태 해시는 튜토리얼이 켜져 있을 때만 단계를 넣습니다. 일반 게임의 해시는 예전과 같습니다.

### 공개 API (ABI 15) — `core/include/castle_core.h`

```c
int32_t core_guide_start(CoreWorld *world);                 /* 새 게임 첫날에만 */
int32_t core_guide_view(CoreWorld *world, CoreGuideView *out); /* 해낸 행동 단계는 먼저 넘김 */
int32_t core_guide_next(CoreWorld *world);                  /* 정보 단계만 */
int32_t core_guide_skip(CoreWorld *world);                  /* 안내 끄기 */
```

`CoreGuideView`: 켜짐·끝남·단계·단계 수·종류·시간 멈춤·강조 대상(`CoreGuideTarget`, `CoreGuideUi`)·권하는 칸(`hint_*`)·도로의 끝 칸(`goal_*`)·진행(`progress`, `progress_need`, `progress_label`)·제목·설명.

### 저장 (스키마 14)

`[progress]` 섹션의 필수 키 `guide=켜짐,단계,예약`. 켜짐은 0/1, 단계는 0~14, 예약은 0, 꺼져 있으면 단계도 0이어야 합니다. 자세한 형식은 [SAVE_FORMAT.md](SAVE_FORMAT.md).

### 화면 — `game/src/ui/tutorial.c`, `tutorial.h`

- `game_tutorial_start`: 메인 화면과의 약속 함수. 튜토리얼 게임을 시작하고 `core_guide_start`.
- `game_tutorial_update` (게임 중 매 프레임): 지금 단계를 받아 시간 멈춤·되돌리기, 단계가 바뀌면 소리, 화면 이동 단계에서 카메라가 움직이면 `core_guide_next`.
- `game_tutorial_draw`: 강조와 안내 창. HUD·건설 막대가 그릴 때 `game_tutorial_anchor`로 단추·탭·카드의 자리를 알려 주면 같은 프레임에 그 자리를 강조합니다.
- `game_tutorial_covers`: 안내 창 위의 클릭이 지도에 짓지 않도록 `render/world.c`의 `world_mouse`가 묻습니다.

### 콘솔판

`cli/commands.c`의 "상태 보기"가 튜토리얼 세이브이면 지금 단계의 제목·설명·진행을 한 줄로 보여 줍니다.

## 검사

| 검사 | 내용 |
|---|---|
| `guide_start_and_info_steps` | 일반 게임은 꺼짐, 시작·두 번 시작 거절, 정보 단계 넘기기, 행동 단계는 "다음"으로 못 넘김, 건너뛰기, 하루 지난 게임은 시작 거절 |
| `guide_full_playthrough` | 시드 42·평화에서 공개 API만으로 끝까지: 권하는 자리에 실제로 지어지는지, 일꾼 배치, 길을 찾아 도로를 이어 연결 도로 10칸, 방어 두 건물, 촌락 |
| `guide_holds_raids_until_defense` | 방어 단계 전에는 습격을 하루 미루고, 건너뛰면 바로 옴 |
| `guide_save_roundtrip` | 저장 → 불러오기 후 같은 단계·같은 해시, 일반 게임과 해시가 다름 |
| `load_rejects_bad_values` | `guide=` 의 잘못된 값과 빠진 키를 거절 |
| `tutorial_objectives` | 모든 게임의 처음 목표 5개 (쓰지 않던 옛 목표 코드를 지우며 실제 목표로 바꿈) |
| 스크린숏 | `castle_game --screenshot 파일.png --screen tutorial` (환영 단계), `--screen tutorial_build` (텃밭 단계의 강조) |

## 단계를 고치거나 더하려면

1. `core/src/tutorial.h`의 단계 번호 enum과 `core/src/common/tutorial.c`의 `GUIDE_STEPS`에 한 줄을 더합니다. 번호는 세이브에 남으므로 중간에 넣으면 스키마를 올려야 합니다 (끝에 더하는 것은 `GUIDE_STEP_COUNT`만 바뀜 — 읽기 범위가 넓어질 뿐 예전 세이브는 그대로 읽힘).
2. 행동 단계면 `done` 함수를 쓰고, 필요하면 `progress`·`build_type`·`building` 함수를 씁니다.
3. 강조할 새 화면 요소가 있으면 `CoreGuideUi`에 번호를 더하고, 그 요소를 그리는 곳에서 `game_tutorial_anchor`를 부릅니다.
4. `tests/test_guide.c`의 끝까지 진행하는 테스트를 고칩니다.

## 한계

- 일꾼 배치 단계는 검사창 안의 "일꾼 배치" 단추를 강조하지 않습니다 (검사창은 튜토리얼 작업의 담당 범위 밖). 지도에서 일터를 금색으로 표시하고 설명으로 안내합니다.
- 정보 단계("시간 다루기" 제외)에서는 배속 단추를 눌러도 시간이 멈춘 채로 있습니다. "다음"을 누르면 원래 배속으로 돌아갑니다.
- 사람이 처음부터 끝까지 해 보는 확인은 아직입니다 (자동 테스트는 공개 API로 끝까지 진행).
