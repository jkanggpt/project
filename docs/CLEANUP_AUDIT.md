# 소스·에셋·저장 구조 정리 감사

검사일: 2026-11-26~27. 기준 커밋: 630ab27. 작업 브랜치: codex/structure-cleanup. 현재 릴리스 표시는 1.2.4, 저장 스키마는 13, 공개 ABI는 14입니다. Windows 범위의 구조 정리와 검증을 완료했습니다.

## 범위와 보존 기준

사용자가 제공한 소스·에셋·저장 통합 명세를 적용했습니다. 추가 답변 ‘콘솔도 현행 규칙으로 통합’을 우선하여, 그래픽과 콘솔이 같은 160×160 지도·73건물·실제 이동/전투 실행기를 사용합니다. 별도 구 게임 루프와 구 저장 이관은 제거했습니다. 경제·전투·성장 수치와 실제 원화는 변경하지 않았습니다.

AGENTS.md는 시작 SHA를 유지하고 OS 사용자 저장은 변경하지 않았습니다. docs.zip·tools.zip은 사용자가 직접 이동 또는 삭제했다고 2026-11-27 확인했습니다. 두 참고 자료의 시작 기록은 남기되 현재 실재 파일이나 검증 통과 대상으로 세지 않으며 복구·스테이징하지 않습니다. 과거 커밋 이력은 수정하지 않습니다. 검증 전후 로그와 작업 중 격리는 build/reports/structure-cleanup에 있고 출시물에 포함하지 않습니다. 사용자의 최신 지시에 따라 작업 브랜치를 커밋하고 원격 저장소에 푸시합니다. main 푸시와 병합은 하지 않습니다.

## 전수 원장과 이관

- [전체 시작 파일 1,887개 원장](audit/files.json): 시작 경로·크기·SHA256·생산자·소비자·동적 참조·최종 정본·판정과 근거를 기록했습니다. 사용자 지침 1개와 사용자가 직접 이동/삭제한 외부 참고 자료 2개를 구별했습니다.
- [함수 75개 매핑](audit/symbols.json): 69개 현재 기능 이전, 3개 자원 예산 함수의 독립 투영 재구현, 3개 구 저장 이관 함수 제거입니다. 다른 일반 파일의 역할 이동은 원장의 target_path를 따릅니다.
- [기존 CTest 277개 대응표](audit/tests.json): 현행 265개 유지, 아트 검사 8개 통합, 지도·구 저장 혼합 1개를 현재 지도와 안전 거부로 대체, 구 저장 전용 3개 제거입니다. 최종 등록은 272개입니다. 단순 테스트 건수 비교로 범위 보존을 판정하지 않았습니다.
- 현재 실물 원장은 tools/audit_project.ps1로 재생성합니다. build/reports/structure-cleanup/final-audit/current_inventory.json과 result.json에 현재 파일과 패키지 검사 결과를 기록합니다.

미사용 런타임 777파일, 제작 입력 8파일, 과거 문서·QA 150파일, 분리 이름 3파일, 구 저장 fixture 3파일을 개별 검증 후 소스 영역에서 격리했습니다. 앞서 옮긴 구 도구·메타데이터·별도 콘솔 실행기 45파일과 함께 retired_files.json에 SHA와 대체 경로를 기록했습니다. 이전 생성 DLL도 실행 경로가 없는 빌드 산출로 분리했습니다. 외부 링크는 이동하지 않았으며 절대 경로가 프로젝트 내부인지 확인했습니다.

원본과 생성 결과가 같은 바이트인 오디오·폰트는 제작 입력과 런타임 출력이라는 서로 다른 역할로 원장에 등록했습니다. 임의 중복 정본으로 취급하지 않습니다. 테스트의 독립 기대값도 카탈로그 구현을 그대로 호출하는 대체물로 바꾸지 않았습니다.

## 단일 구현과 공개 헤더

core/src는 common/world/people/buildings/economy/ecology/services/combat/persistence로 분리했습니다. game/src는 runtime/render/assets/ui로 분리했고 콘솔의 독자 Walker/Battle은 공용 GameSession으로 대체했습니다. 구 생산·주민 AI·이주·연구·승급·습격 일정 루프와 현재로 생성할 수 없는 날씨·전투·표시 분기를 제거했습니다.

현재 CoreDefs와 파일 정의는 73건물·28적·24연구·6등급의 같은 카탈로그에서 생성합니다. 초기 자원도 한 상수 표를 사용합니다. CoreNewGameParams.ruleset의 기존 0/1은 ABI 입력 별칭으로 모두 현재 월드를 만들며, 읽는 저장은 ruleset=1만 허용합니다. 별도 구 버전을 선택하는 모드는 없습니다. 스트레스 도구는 현재 모델에 큰 영지를 구성합니다.

공개 선언은 core/include의 두 헤더만 유지했습니다. 프런트 복사본에는 정본에만 있던 CoreEnemyRuntime, core_get_villager와 다수 현재 확장 API가 누락되어 있었습니다. 역방향 고유 선언은 없었습니다. header_diff.json에 실제 차이를 보존하고 소비자를 정본으로 옮겼습니다. 공개 API 148개 주소를 실제로 링크하며 C++11에서 두 포함 순서를 검사했습니다. MinGW 공유 DLL의 import library를 통한 148개 API 링크·실행도 성공했습니다. 확장 헤더의 extern C 가드도 보완했습니다. 기존 requires 필드로 인해 C++20 호환은 검사 범위가 아닙니다.

## 빌드·검사·성능 영수증

실제 도구는 CMake 4.3.2, Visual Studio 2019 MSVC x64, MinGW GCC 16.1/Ninja입니다. Godot/.NET은 설치되어 있지 않고 현재 게임에 필요하지 않습니다. 독립 소스는 한글과 공백이 있는 ‘독립 소스’ 경로에 필요한 파일만 복사했으며, 기존 빌드 캐시 없이 동봉 raylib 아카이브로 구성했습니다. MSVC 정적·공유 코어와 콘솔·게임·도구가 모두 링크됩니다.

최종 회귀·성능·패키지 수치는 아래 최종 결과와 영수증에 기록했습니다. 장기 비교 중 존재했던 성장 미달은 [기능 한계](MISSING_FEATURES.md)에 따로 기록합니다. Linux ASan/Clang, 사람 30분 플레이, 도시 30판, 최대 32어선과 모든 회전 건물 동시 부하는 미검증입니다.

### 화면과 경로

최초68PNG와 최종 설치본16PNG를 수집했습니다. 선택 카드·알림·농업·어선·상인 화면을 4해상도에서 직접 검토했고 필수 텍스처 오류는0입니다. 최종16장 중8장은 앞선 PNG와 바이트까지 같습니다. 실시간 효과가 있는 나머지는 PNG해시만으로 같다고 판정하지 않고 화면을 직접 확인했습니다. 407실제 에셋 자체의 바이트 보존은 별도로 전부 검사했습니다.

시작1,887경로 중 현재 프로젝트에 해당하는 대체 경로는 모두 실재하고 미해결0입니다. 사용자 이동/삭제 확인을 받은 외부 ZIP2개는 대체 경로 존재 검사에서 제외하며 AGENTS.md는 시작 SHA를 유지합니다. 현재 실물 원장의 true/false 값은 해당 단계의 전역 검증 및 의도된 패키지 제외 범위를 나타내며 모든 함수 분기의 실행 커버리지라는 뜻이 아닙니다.

## 경로와 향후 운영

런타임 목록은 game/assets/assets_manifest.json, 제작 입력/권리는 art/art_manifest.json, 단계 순서는 art/recipes/pipeline.json 한 벌입니다. 설치는 CMake Runtime 컴포넌트를 사용하며 raylib 개발용 헤더·정적 라이브러리, 원화, 과거 문서, 테스트 산출을 넣지 않습니다. 정의도 cmake/Data.cmake의 실제 6파일만 복사합니다.
