# 생성형 AI 사용 기록

Codex가 학생의 지시에 따라 코드 작성·구조 정리·문서화·검증을 수행했습니다. 현재 구조 정리 세션에서는 하위 에이전트와 새 이미지 생성을 사용하지 않았습니다. 외부 업로드 없이 로컬 커밋으로 마무리합니다.

| 범위 | 수행 내용 |
|---|---|
| core/src 역할별 모듈 | 기존 현재 규칙의 함수 이전, 중복 규칙 제거, 단일 저장 스키마와 안전한 검증 |
| game/src, cli | 공용 실행기를 통한 그래픽·콘솔 규칙 통합, 단일 공개 헤더 참조 |
| tools/art, cmake | 소스 포함형 팩커를 정상 C 모듈로 통합, 매니페스트 기반 복사·설치 |
| tests | 현재 기능 사례 이전, 구 저장 호환 사례를 안전한 거부·현재 왕복 검사로 대체 |
| docs | 현재 규칙·코드 읽기·권리·검증 근거를 역할별 정본으로 통합 |

기존 원화는 내장 image_gen으로 생성했고 C 도구로 잘라 배치·알파 처리·아틀라스 합성을 했습니다. 원화·음원·폰트의 실사용 407파일은 구조 정리 전후 바이트가 같습니다. 전문 생성 요청 22문서와 원래 메타데이터 6개는 art/recipes/provenance.json에 보존했습니다. 과거 이름은 출처 증거에만 남으며 빌드나 런타임의 분기 기준으로 사용하지 않습니다.

자동 검증 결과와 한계는 CLEANUP_AUDIT.md, MISSING_FEATURES.md에 기록합니다. 사람이 실제 수행하지 않은 장시간 플레이나 지원 환경 검사를 통과로 표시하지 않습니다.
