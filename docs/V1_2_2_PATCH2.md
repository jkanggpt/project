- 주민 식사: 합류한 주민 한 명당 하루 1.0, 하루 한 끼. 겨울 12일은 12.0/인, 승급의 식량 일수도 같은 기준. 가축 사료 수치는 유지합니다.

- 재입고 기본량: 노점30 / 시장120 / 교역소390. 기본량 50% 증가 후 5개 단위 반올림. 능률 배율 M(E)=1+0.30×clamp((E−1)/6.5,0,1)−0.10×clamp((1−E)/0.75,0,1), E=0.25~7.5. 최종 재고도 5개 단위로 반올림합니다.

- 환복: 수렵/군사 일터 도착 → 실내 진입 → 환복 → 출동. 퇴근/다른 일터 배치 때에도 이전 일터로 돌아가 실내에서 평상복으로 바꿉니다. 환복 상태와 일터·완료 시각은 기존 저장10의 임무 필드에 보존합니다. 일터가 파괴되어 사라졌다면 평상복으로 복구합니다.
