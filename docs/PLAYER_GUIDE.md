# 마법성채 키우기

압축을 푼 뒤 castle_game.exe를 실행하세요. assets와 data 폴더를 함께 두어야 합니다.
게임은 C11/raylib로 실행되며 Godot·.NET·Python 설치가 필요하지 않습니다.
저장은 사용자 게임 데이터의 saves 폴더에 저장됩니다. 이전 형식은 지원하지 않으며 새 게임을 시작해야 합니다.
마우스로 건설·주민·시설을 선택하고 화면의 도움말에서 조작법을 확인하세요.
저장 슬롯의 .bak은 같은 스키마의 장애 복구용 파일입니다.
제작·권리 고지는 CREDITS.md와 assets/licenses, licenses 폴더를 참고하세요.
