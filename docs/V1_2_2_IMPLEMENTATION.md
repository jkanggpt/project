# v1.2.2 구현 기록

기준은 [사용자 명세](V1_2_2_SPEC.md)와 대화의 추가 요구입니다. C11/raylib를 유지하며 Godot/.NET/Python 없이 실행합니다. 검증 수치와 한계는 최종 QA 기록에 따로 기록합니다.

## 게임 규칙과 저장

ABI12/저장10, 군영65를 기존 건물 ID 뒤에 추가했습니다. XP는 실제 노동6시간마다 원배분6XP와 지능½을 적용하고 분야별 미정산 분자·분수를 저장합니다. 같은 경비 분야에서 탑과 병영을 바꾸어도 과거 노동의 가중치를 바꾸지 않습니다. 근무·정찰·순찰·실제 공격·수면·자유시간을 별도로 처리합니다.

주민과 탑의 공격 중간 상태·복장·대기시간, 비행 투사체, 적 HP/공격/진입 경유점/철수 상태도 저장합니다. v9 가져오기는 원본 파일을 보존하고 빈 v10 수동 슬롯에만 새 파일을 만듭니다. 기존 호수·광상·나무·탐험·개인 ID를 재생성하지 않으며, 기존 돌 광상은 독립 돌층으로 옮깁니다. 오두막은 기존 점유 위치와 입구를 보존하도록 방향의 홀짝을 바꾸어 이관합니다.

## 지도·경제·방어

새 지도에는7개 연결 호수와 광종별 연속 광맥, 물/건물/다른 광종 아래에도 독립된 유한 돌층을 생성합니다. 기존 자원 아이콘 장식은 바위 오브젝트로 교체했습니다. 나무 성목 판정은 참나무16/소나무28/자작48/마력72일의 공통 함수를 사용하며 균등 벌목·마력수 재발아를 적용합니다. 성장 후 이동 비용에도 생물군계 보정을 유지합니다.

영구 이주에는 저장된2~3일 대기와 등급별 식량·인원 조건, 도달 가능한 외곽의 분산 출현을 적용합니다. 영주관은 직원 없이 공격하며 병영/군영·탑·야영지/수렵기지는 실제 근무자와 출동 인원의 공격을 사용합니다. 공격적 야생과 실제 반격 대상을 구별합니다. 일반 야생20종 보상은 기존값의1.5배 올림이며 가축/환상종은 기존 보상을 유지합니다.

습격은72게임시간 공격 후 실제 진입 경로를 거슬러 철수합니다. 막힌 경유점은 우회하고 마지막에는 도달 가능한 외곽을 탐색합니다. 철수 중 신규 공성을 하지 않으며 모든 적이 떠나거나 쓰러질 때까지 건설 잠금이 유지됩니다. 공사장은 공격/공성 표적에서 제외하고 진행도·신규 공사·승급·수리를 멈춥니다. 비전투 HP0 파괴는 즉시 폐허로 전환합니다.

## 일정·방문·기분·거래

탑2명은06~18/18~06 실제 교대를 하며 공격을 수행한 담당자가 전투 중 교체되지 않습니다. 실제12시간 근무와 XP9시간 상한을 분리하고 야간 변경 수면 적응을 저장합니다. 병영/군영은08~18, 수렵은07~16에 활동합니다. 문화·교육 직원은 오전/저녁 분할 또는 겹치는 교대를 사용하며 실제 현장 교원의 자격을 확인합니다. 수업과 연구는 같은 노동 시간을 두 번 사용하지 않습니다.

방문은 필요 행동 뒤에 기분·거리·정원으로 추첨하고 예약·이동·체류 후에 보상합니다. 문화2일 재방문·하루 문화1/교육1, 보호구역 내부20~60분 산책과 출발점 복귀를 처리합니다. 기분은 실제 식사/음수/근무/수면/위험/피격/사망 목격/최종 철수 사건별 쿨다운과 하루 상한을 사용합니다. 잠자는 동안 작은 허기 벌점은 중지하며 기존 행복도 공식과 하루2의0방향 회귀를 유지합니다.

거래는 현장 직원의 현재 평균 능률로 기본20/80/260의90~125%를 즉시 사용합니다. 직원 변경으로 사용량을 지우지 않습니다. 재입고는 저장된 날짜에 한 번만 이루어지며 다음 간격을6/5/4일로 확정합니다. 새벽 정산 시에는 직전 실제 근무의 능률을 사용하므로 직원이 퇴근했다는 이유로 항상6일이 되지 않습니다.
