# v1.2.2 구현 기록 (진행 중)

기준은 사용자 제공 [명세](V1_2_2_SPEC.md)와 대화의 추가 요구입니다. 제안값은 명세의 초기값을 적용하며, 실제 검증 전의 구현을 완료 판정으로 표시하지 않습니다.

## 현재 적용 구조

- C11/raylib 유지. ABI12, 저장10, 원래 건물 번호 뒤에 군영65를 추가했습니다.
- `expansion_v122.c`는 나무 성목 공통 API, 새 호수/광맥/전 타일 돌층, 종류별 번호, 직종 일정, 시설 범위/주변 재고, 기분·여가·군사 출동을 담당합니다.
- v9 읽기를 허용하고 광물/호수/기존12외형을 재생성하지 않습니다. 기존 돌 재고는 독립 돌층으로 옮기고, 기타 타일에만 시드 기반 기본 돌층을 추가합니다. 고갈된 기존 돌층0은 보존합니다. 이미 대기 중인 마력수만 비례 보정합니다.
- 기존 오두막의 점유 위치를 보존하기 위해 이관 시 회전 번호의 홀짝을 바꿉니다. 새 오두막은 정/후면2×3, 측면3×2입니다.
- 종류별 표시번호는 내부 고유 ID와 별도로 저장하며 사용한 번호를 재사용하지 않습니다.
- 확장 습격에 ASSAULT/RETREAT와72시간 타이머를 도입하고 진입 위치·경유점·HP·공격 중간상태를 저장합니다. 실제 완전 철수 전까지 건설 잠금을 유지합니다. 습격 종료 검증과 추가 비행체/일정 상태 검증은 진행 중입니다.
- UI는 공통 시설 질의와 실제 배치/현장 근무·F·주변 재고·공격 수치를 읽습니다. 고정 생산성100% 표시는 제거했습니다.
- 추가 요구: 공사장 그림 전체 점유 크기, 건설 분류 순서, 철거 모드 붉은 타일·테두리·X 표시, 광신도/코카트리스/히드라/농장/과수원 원화를 작업 중입니다.

## 그림의 사용자 교정

초기 신규 주민36종의12×6 배치 시안과 초기 농장 시안은 화풍이 달라 적용하지 않습니다. 이후 실사 비율에 가까운 주민 시안도 적용하지 않습니다.
주민은 **기존 원본4열×6행**, 남녀 각각 정/측/후3행×걷기4프레임을 유지하고, 기존 얼굴·비율·선·픽셀 음영을 직접 참조해 머리/옷만 바꿉니다. 원래12외형은 그대로 유지합니다.
농장은 기존 텃밭·주택·밀밭을 직접 참조해 촘촘한 식물/흙 질감과 가는 울타리를 유지하며4방향·계절별로 제작합니다.
