# 자연 풍경 GPU 실험실

압축을 푼 뒤 `demo.cmd`를 실행합니다. OpenGL 4.3 이상을 지원하는 그래픽 드라이버가 필요합니다. 실행 파일과 `assets` 폴더를 함께 둡니다.

기존 2D 원화 위에 같은 크기의 픽셀로 초지·해안·포석·물결·연기·큰 그림자를 그립니다. 기본 표시 배율은 3배입니다. 자연 지면은 월드 좌표에서 이어지고, 목조 다리와 포석은 구조가 읽히도록 유지합니다.

| 조작 | 기능 |
|---|---|
| 마우스 휠 | 정수 확대 1~6배 |
| 가운데 버튼으로 끌기 | 지도 이동 |
| 1 / 2 | 낮 / 밤 |
| 방향키 | 태양 방향·높이 |
| 오른쪽 버튼 누르기 | 이동하는 횃불 |
| S / G / L / W / M | 그림자 / 풀 / 잎 / 물 / 연기 전환 |
| Tab | 최종 화면 / 원화 / 법선 / 햇빛 그림자 |
| H | 안내 표시 |

`check.cmd`는 픽셀 확대, 실제 알파 접촉, 청크 이음새, 풀의 종류·배치·제한 수, 연기의 크기·불투명도를 검사합니다. `benchmark.cmd`는 Windows 11의 RTX 4060에서 네 해상도의 기준·효과·기준 측정을 기록합니다. 소프트웨어 렌더러를 하드웨어 결과로 기록하지 않습니다.

`shadow-demo.cmd`는 밑선 절단을 살펴보는 확대 장면입니다. 3은 바위, 4는 인물, 5는 나무, F는 좌우 반전입니다. 방향키로 태양을 돌리거나 2로 밤을 켜고 오른쪽 버튼으로 횃불을 옮깁니다. 위쪽 그림자는 둥근 체적을 유지하고, 아래쪽은 실제 원화의 밑선에 맞춰 잘라 냅니다. `check.cmd`는 세 종류·좌우 반전·다섯 조명, 30개 조합의 부유 타원과 그림자 연결도 검사합니다.

```powershell
# 더 많은 광원과 30분 자원 검사
powershell -NoProfile -ExecutionPolicy Bypass -File .\benchmark_gpu.ps1 -Extended -SoakMinutes 30

# 이전 화면 맞춤 비교 장면
.\castle_gpu_lab.exe --scene reference

# 원화 밑선과 둥근 그림자 절단 검사
.\castle_gpu_lab.exe --check-shadow-cut

# 1080p 낮 화면 저장: 실제 표시 픽셀 포함
.\castle_gpu_lab.exe --scene natural-slice --pixel-scale 3 --width 1920 --height 1080 --time 11 --frames 8 --capture day.png
```

새 측정에는 표시·논리 해상도와 원래 GPU 제출 프레임 번호가 함께 기록됩니다. 이전 실험의 화면 맞춤 성능 수치와 직접 비교하지 않습니다. 장시간 실행은 최근 표본을 60프레임마다 최대 6,000개 보관하고, 자원 검사는 실행 전체에서 계속합니다.

그림자의 앞선은 실제 원화 알파에서 추출합니다. 이 앞선을 둥근 상체와 수관에도 적용해 밑선 아래에 별도의 타원이 뜨지 않게 합니다. 가려진 발자국 깊이와 높은 부분은 근사이며, 자동 접촉을 모든 그림의 수동 검수 결과로 표시하지 않습니다. 이 배포본은 MinGW의 경고 오류 빌드로 만든 Windows 실행 파일입니다. MSVC 빌드와 이번 외형의 실제 RTX 성능 측정은 별도 확인 항목입니다.
